# 2026-11-04 — 浅色方案的原生实现映射

用户确认方案后，使用 Kotlin / Compose Multiplatform 落地。`index.html` 和原 156 张图保留为设计阶段记录，实际界面与验证以[本次变更](../../../../docs/changes/2026-11-04-06-native-light-ui-and-continuous-navigation.md)为准。原生采用 dp/sp、真实曲库封面、平台字体和系统对话框，不复制浏览器模拟业务或虚构数据。

| 提案页面/状态 | 原生落点 | 实施方式 |
| --- | --- | --- |
| 曲库歌曲/歌单/专辑/歌手 | `LibraryScreen`、`PlaylistListTab`、`CollectionGrid` | 开放正文、统一分段选项；收藏入口，2/3/4 列封面网格；保留排序、多选与歌曲操作 |
| 歌单/专辑/歌手/收藏详情 | `LibraryDetailView` | 桌面封面与内容横排，手机紧凑头部，真实播放/随机播放/管理操作 |
| 本地/在线/描述搜索 | `DiscoverScreen`、`OnlineSongSearch`、`SemanticSongSearch` | 共用新壳层/色板/控件材质；原搜索、匹配、试听和下载链路保留 |
| 每日推荐、历史、反馈、推荐计划 | `RecommendationsScreen`、`RecommendationHistoryScreen`、设置 Recommendations 分组 | 共用新主题；计划进入独立设置分组，真实推荐与反馈流程保留 |
| 播放器封面/歌词/队列、定时/音效/来源 | `NowPlayingOverlay`、既有原生弹窗 | 顶部分栏、连续切换、手机及宽屏控制台；歌词保持稳定排版；分栏使用真实内容生命周期 |
| 助手对话/欢迎/历史/歌曲附件 | `AssistantScreen` | 统一正文边距、主题及固定底座；消息和历史仍使用实际会话数据 |
| 共听创建/加入/房间/成员/队列/AI/伙伴/指南 | `TogetherScreen`、`TogetherRoomComponents` | 开放式头部、统一面板与留白；邀请、聊天、主持权限和连接状态保留原路径 |
| 工具、导入/转换/进度、歌单包导入导出/预览 | `ProfileScreen`、`ImportScreen`、`SyncScreen`、`SyncPackageDialog` | 开放式工具正文、统一列表入口/弹窗；系统选择器、转换和数据校验不变 |
| 任务、歌源/来源偏好、空间/清理、管家/重复检查、品味/维度 | 相应工具目的地 | 新工具框架、主题和统一边距；操作、预览、确认与服务状态保留 |
| 设置索引 | `SettingsScreen` | 八个原生分组入口，可通过顶栏或系统返回回到索引 |
| 外观/天气、播放、歌词翻译、API、推荐、语音、B站账号、目录 | `SettingsSection` + `AppearanceSettings` + `MusicFeatureSettingsSection` | 现有表单迁入对应分组，不增加配置键；教程按目标自动打开分组 |
| 登录状态、教程/章节、音量平衡说明、关于/更新/支持作者 | 既有原生页面及弹窗 | 继承新主题与页面框架，保持现有平台能力与确认行为 |
| 新建/编辑/多选/添加歌单/补全/截图导入/B站导入/分享/删除 | 既有原生编辑器和确认弹窗 | 共享色板、圆角与材质生效；保留焦点、校验、进度和危险操作确认 |
| 空曲库、加载/缓冲、播放失败、悬浮歌词 | 既有空态/错误/加载组件及平台悬浮层 | 新主题继承；悬浮窗口生命周期、权限和播放错误恢复语义不变 |

桌面侧栏为 232dp，公共工具栏固定在正文上方，播放条固定在下方；手机仍使用音乐库、音乐助手、一起听、工具四项导航与迷你播放器合并底座。720–1099dp 使用导航 rail，1100dp 起使用侧栏。 短横屏（高度 <480dp、宽度 ≥480dp）改用 72dp 图标 rail 与 60dp 紧凑播放器，曲库短高标题减少留白；顶部返回经窗口局部 UiBackDispatcher 复用 Android/桌面当前活动返回回调，先退出详情或设置分组。主色默认玫瑰色，用户已存储的深色/系统/天气选项继续生效。

主导航、曲库标签、详情、设置分组和播放器分栏共享 280ms / 12dp 转场，新旧页面同时存在，固定壳层不参与位移；减少动效与键盘导航即时。转场测试验证旧实例保留、反向复用与打断后释放，不能用该测试宣称真机 120fps。

## 原生验证证据

`UiVisualContractTest` 使用模拟服务与测试曲库，通过原生 `ImageComposeScene` 渲染 390×844 和 1440×960，逐个切换主页面、曲库标签、设置分组与播放器分栏，并检查按钮语义。输出目录为 `composeApp/build/light-ui-native/screenshots/`；已有大字/横屏/空态/错误/深色测试继续执行。没有把 HTML 截图当作原生截图。

78 项方案覆盖的是功能入口和代表状态，不是 78 个独立 Kotlin 路由。本轮不会为每种弹窗业务组合另建页面；真实联网、登录、音频转换、系统授权和多设备共听没有通过模拟截图冒充端到端验收。
