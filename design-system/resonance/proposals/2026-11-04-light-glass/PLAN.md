# 2026-11-04 — Resonance 全页面浅色 UI 提案

本轮是供选择与试用的设计方案，尚未替换原生实现。Android、Windows、Linux 继续使用 Kotlin / Compose Multiplatform。独立官网与论坛不在此次范围内。

## 设计方向

参考用户提供的音乐播放器：半透明侧栏、大幅专辑封面、由封面延伸的背景颜色、悬浮播放控制。浅色版本把主文字稳定放在雾白表面上，强调色只用于当前选择、歌词焦点和主操作。

| 角色 | Token | 用途 |
| --- | --- | --- |
| 主画布 | #F3F5F8 | 长时间阅读与曲库浏览 |
| 透色表面 | #FFFFFFD9 | 导航、输入、播放控制 |
| 主文字 | #25303C | 标题、歌曲、主要操作 |
| 次文字 | #5C6572 | 歌手、来源、说明 |
| 强调色 | #A53649 | 当前歌词、播放反馈与主操作 |
| 浅强调背景 | #F1DFE4 | 选中标签与聊天气泡 |

字体使用平台 Sans Serif，原型优先 Noto Sans CJK SC；原生实现应映射到 Material Typography 与 sp，不能照搬浏览器像素。页面标题 27–34px，桌面音乐详情 46px，正文 13–14px，歌词手机18px / 桌面23px。原型小字仅用于辅助信息；原生落地需进一步按系统字体缩放与48dp触摸目标验证。

## 页面结构

桌面：224px 侧栏 + 开放正文，底部播放条横跨内容区域。曲库使用列表/网格，详情封面与介绍并排。播放器保留封面、歌词、队列三个视图；歌词模式为左封面、右歌词。

手机：四项底部导航（音乐库、助手、一起听、工具）与迷你播放器合为一个底座。正文单列，歌曲网格两列，播放器展开为全屏。歌词使用稳定行高，颜色与位置连续变化，不通过字体大小跳动吸引注意。

设置由长表单整理为分组入口和独立子页，原有功能继续保留；此结构是提议，未改变原生 LibraryDestination。

[覆盖清单](COVERAGE.md) 按现有关键符号关联 **78 个页面与关键状态**，每个都有桌面和手机图，共 **156 张**。不是78个全新产品路由。常见弹窗以独立画板便于看图；实际交互中的邀请、歌曲菜单等使用有焦点管理的原生 HTML dialog。图片是首屏构图，长页面可在原型中滚动查看完整内容。

## 试用顺序

1. 打开 `index.html`，通过顶部页面菜单快速切换；“全部页面图片”打开 `gallery.html`。
2. 点击底部迷你播放器：展开/收起；点击封面、歌词、队列；点击播放开始歌词焦点演示（无音频）。
3. 点歌词行，观察连续定位；快速开关播放器，检查能否中途反向。
4. 试本地搜索、空结果、助手输入、加入队列、房间聊天、邀请确认、睡眠定时。
5. 点击“手机预览”或缩小浏览器窗口；点击“减少动态”对比。

所有歌曲、聊天、统计和房间都是演示数据。下载、连接、付费服务、支付、删除和文件写入用明确的演示反馈表示，不执行真实动作，不保存表单凭据。

## 动效方案

| 交互 | 目的 | 实现与参数 |
| --- | --- | --- |
| 主导航、曲库标签与详情 | 避免内容突然替换 | 新旧内容共存；transform 12px + opacity，280ms，复用 --ease-drawer；CSS transition 从当前画面接续，固定导航与播放条节点保持，键盘与减少动态即时 |
| 播放器展开与收起 | 保持迷你播放器到全屏的空间关系 | CSS transform 280ms，cubic-bezier(.32,.72,0,1)，opacity 200ms |
| 歌词焦点 | 表明当前行，避免字号跳变 | 行高68px，transform 280ms，颜色200ms；点击和模拟播放驱动 |
| 按钮反馈 | 即时回应点击 | scale(.97)，140ms，cubic-bezier(.23,1,.32,1) |
| 轻提示 | 显示操作结果 | opacity/transform 200ms，可重复触发并重新定时 |
| 键盘与减少动态 | 避免不必要的位移 | 键盘操作即时；prefers-reduced-motion 与原型开关关闭位移动画 |

没有动画模糊半径、背景持续漂移或逐行模糊。玻璃仅用于少数固定表面，列表直接使用透色底。

## 原生落地建议（尚未实施）

1. 先确认该方案的配色、桌面/手机密度与歌词手感。
2. 从共享主题、导航底座、曲库与详情落地，使用现有状态与回调。
3. 将播放器、助手、一起听分组落地，保留快速切歌代次、共享队列和消息归属。
4. 完成工具、设置、弹窗；不改变原子存储、转换、删除和付费授权边界。
5. Android 真机及 Windows/Linux 原生窗口检查字体缩放、系统栏/IME、触摸/鼠标、返回、性能。浏览器截图不替代这一步。
