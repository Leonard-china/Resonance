# Resonance v0.2.0

## 重点更新

- 新增无需粘贴文本或 API Key 的自动歌词：优先按完整曲目签名精确匹配，支持严格搜索回退、逐行 LRC、本地缓存、自动滚动、点按跳转和强制刷新。
- 新增沉浸式全屏播放页，包含动态环境色、立体封面、播放模式、歌词与当前队列；手机竖屏、横屏及宽屏会按可用空间自适应。
- 修复扫描成功后本地曲目仍无法在音乐库中浏览的问题；新增“全部歌曲”和“我的收藏”快速入口。
- 精简手机迷你播放器，只保留高频播放操作，把完整模式控制收进全屏播放页，降低小屏拥挤。
- 增加首次加载反馈、加载异常提示、48dp 触控目标、自动歌词来源/隐私说明与本地缓存状态。

## 稳定性与安全

- 修复 Android 8/9 可能因直接引用 API 29 `RecoverableSecurityException` 而触发的兼容性问题。
- 播放服务改为不对其他应用导出；应用数据同时禁用云备份和设备迁移备份。
- 消除静态 Activity/ContentResolver 引用，避免封面解析路径持有界面上下文。
- 局域网同步空间检查改用 Android StorageManager 可分配容量，并保留兼容回退。
- 修复两个依赖开发机外部文件的测试，使完整测试套件可在干净环境重复运行。
- 构建脚本自动选择 JDK 17–21，并对当前不兼容的 JDK 25 给出明确错误。

- Android / Windows versionName：`0.2.0`
- Android 最低版本：Android 8.0（API 26）
