# Resonance v0.2.2

## 重点更新

- **修复灵动岛与系统媒体通知跳转**：为 Android `MediaSession` 配置标准启动 `sessionActivity`（PendingIntent），彻底解决在小米 HyperOS 焦点通知/灵动岛、Vivo OriginOS 原子岛、OPPO ColorOS 流体云等系统中，点击灵动岛浮窗卡片无法跳转切换到应用主界面的问题。
- **流体环境光画布**：新增 `FluidAmbientCanvas`，提供通透的水润磨砂玻璃质感与动态微光氛围渐变。
- **UI 与动效质感打磨**：全面优化全屏播放页、歌单对话框、歌曲信息编辑面板、AI 批量补全对话框及睡眠定时器的布局与弹性交互动效。
- **全功能集合**：包含 v0.2.0 ~ v0.2.1 的完整功能更新（DeepSeek AI 智能元数据补全与歌词生成、KGG v5 本地解密、KRC 歌词解析、Windows 桌面悬浮歌词与局域网免扫码极速同步）。
