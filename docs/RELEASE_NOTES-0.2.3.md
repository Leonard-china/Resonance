# Resonance v0.2.3

## 重点更新

- **歌词平滑卷动动画**：
  - **封面歌词预览动态卷动**：优化全屏播放封面面板下方的三行同步歌词预览，通过 `AnimatedContent` 与高阻尼弹性物理曲线（`spring`），在切换歌词行时呈现连续纵向平滑推卷与淡入淡出动效，彻底告别直切生硬感；并补全时间轴偏移量（`offsetMs`）的实时对齐。
  - **全屏歌词垂直居中平滑跟随**：重构全屏歌词面板，采用动态计算居中内边距（`centerPadding`），使当前活跃行（包含首句至末句）始终优雅停靠在屏幕垂直黄金分割中心，消除原有开局 3 句锁死不滚动的硬跳问题。
  - **手势拖拽防抖保护**：支持智能手势感知（`collectIsDraggedAsState`），用户滑动浏览歌词时自动暂停跟随，松手静置或点击任意歌词跳转后平滑归位。
  - **歌词行视觉升级**：当前行高亮放大、边框微光与水润发光底色平滑过渡，非当前行柔和弱化。
  - **桌面悬浮歌词同步升级**：Windows 桌面浮窗歌词同样应用了平滑纵向滚动动画。
