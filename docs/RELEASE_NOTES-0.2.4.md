# Resonance v0.2.4

## 重点更新

- **浅色乳白磨砂与天气自适应配色**：
  - 引入浅灰绿（晴天/多云）与冰蓝银白（雨雪）两套自适应强调配色体系，支持固定浅灰绿、固定冰蓝与随天气自动切换三种模式。
  - 采用局部高不透明度乳白磨砂玻璃表面与克制阴影，全面移除珊瑚与橘黄装饰色，真实音乐封面保留原貌。
  - 支持前台大致定位与手动设置城市天气兜底，网络或定位异常时平滑保持上次配色。

- **多端与多尺寸响应式布局重构**：
  - 针对手机竖屏、手机横屏、平板视口及 Windows 桌面（920×640 紧凑窗至 1920 宽屏）全面适配。
  - 手机横屏优先保障主进度条与播放控制处于首屏可见区域，歌词与播放队列支持平滑向下滚动；平板与桌面端主内容居中限宽（1280dp × 900dp），避免宽屏过度留白。
  - 导航结构清晰收敛为音乐库、搜索与工具三大分区，持久迷你播放器随时进入全屏播放界面。

- **歌词对比度与无障碍交互升级**：
  - 重构歌词时间轴视觉，大幅提升非当前歌词行的实色对比度与可读性，单行交互热区不低于 48dp。
  - 接入系统「减少动态效果」设置并提供应用内独立开关，开启时停用环境流体漂移与弹性位移动画。
  - 核心操作按钮尺寸全量规范至 48dp 以上，补全语义标签与无障碍读屏描述。
