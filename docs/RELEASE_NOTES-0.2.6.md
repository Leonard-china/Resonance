# Resonance v0.2.6

## 重点更新

- **全应用丝滑滑动切换动效 (Smooth Slide Transitions)**：
  - **主导航横向滑动**：音乐库、搜索、工具三大一级标签切换引入基于临界阻尼弹簧（`dampingRatio = 1.0f, stiffness = 420f`）的 35% 视口微距平滑横向推拉（Slide-Fade），起步响应灵敏，收尾丝滑沉稳，彻底告别瞬时直接出现。
  - **工具箱层级钻取与返回**：从「工具」进入「导入音乐」、「设备同步」与「设置」时，享受原生级 100% 满屏自右向左推入（Push），主页 25% 视差滑出；点击返回时，上一级页面自左向右滑回（Pop），详情向右滑出。
  - **音乐库详情页进出**：点击歌单、专辑、歌手及「我的收藏」卡片时，消除原先 0ms 突兀硬切，支持满屏平滑推入与返回滑出。
  - **音乐库 Tab 标签页切换**：吸顶胶囊标签栏配合内容区域跟随点击先后顺序平滑横向滑动切换（歌曲 ⟷ 歌单 ⟷ 专辑 ⟷ 歌手）。
  - **播放器面板切换**：全屏播放器内的封面、歌词与播放队列同级横向顺滑滑动。
  - **无障碍适配**：全链路适配系统 `Reduced Motion`，开启时自动降级为纯柔和淡入淡出。
- **持久化存储优化**：
  - 桌面端配置存储同时支持读取系统属性 `System.getProperty("RESONANCE_DATA")` 与环境变量 `System.getenv("RESONANCE_DATA")`，提升测试与自动化兼容性。
