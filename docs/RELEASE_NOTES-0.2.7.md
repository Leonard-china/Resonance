# Resonance v0.2.7

## 重点修复与体验优化

- **修复歌单切歌与随机播放跨歌单串歌问题 (Playlist Queue Isolation)**：
  - **歌单独立队列隔离**：在歌单详情页点击「播放全部」、「随机播放」或点击单曲时，播放队列严格限制在当前歌单范围内，彻底修复一首歌播放完毕后或随机播放时意外跳到其他歌单歌曲的问题。
  - **ExoPlayer 底层媒体队列精准同步**：向系统底层的播放服务及 ExoPlayer 提交当前歌单的独立音轨序列，确保系统后台播放、锁屏控制器及切歌自动流转始终在当前歌单内循环或随机，不串歌。
  - **队列状态动态自愈**：删除歌曲、批量清理或从歌单移除歌曲时，动态同步更新当前活跃队列，避免死链或越界。

- **全面修复滑动切换动画无动效问题 (Silky Smooth Slide Transitions)**：
  - **解决系统级动效被禁用陷阱**：修复在部分 Android 定制系统（MIUI/HyperOS、ColorOS、EMUI 等省电模式或特定缩放设置下）`ValueAnimator.areAnimatorsEnabled()` 返回 `false` 导致 Compose 所有动画被强制降级为 0ms 瞬间硬切的问题。默认保障原生动效正常流畅执行。
  - **升级满屏丝滑滑移动画**：主导航标签（音乐库、搜索、工具）、二级详情页（歌单、专辑、歌手、我的收藏）、歌单标签栏以及播放器面板切换均采用 100% 满屏位移与 `CubicBezier(0.2, 0.0, 0.0, 1.0)` 贝塞尔曲线（320ms / 340ms），搭配细腻微弱淡入淡出，带来真正丝滑的滑动切换体验。
