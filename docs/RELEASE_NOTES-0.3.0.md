# Resonance v0.3.0 (v3.0)

## 重点功能与视觉体验升级

- **全新应用品牌图标 (New 3D Fluid Musical Note Icon)**：
  - 采用全新 3D 蓝绿青渐变音符视觉设计。
  - 全面更新 Android 自适应图标（Adaptive Icon，432x432 前景与纯白背景层）、全套高清 Legacy Mipmap（mdpi 至 xxxhdpi）以及桌面端应用图标（512x512 Squircle）。

- **歌词体验深度优化 (Immersive Dynamic Lyrics & Smooth Scroll)**：
  - **移除当前行边框与背景框**：去除了原先歌词行外围生硬的色块与边框，还原纯净歌词视图。
  - **当前歌词字体变色高亮**：活跃歌词行以主题色（`ResonanceColors.Primary`）高亮变色发光，配合字重与缩放微动效；未播放歌词行保持优雅柔和半透明。
  - **更平稳缓慢的视口居中平滑滚动**：优化歌词居中算法与动画阻尼（650ms `FastOutSlowInEasing`），彻底告别突变硬跳，歌词流动更平滑自然。

- **全场景切歌丝滑滑动过渡 (Silky Track-Switching Transitions)**：
  - **底部悬浮迷你播放器 (MiniPlayer)**：切换上一首/下一首歌曲时，歌曲封面、歌名、歌手与播放状态以横向弹性滑入/滑出动效呈现，操作反馈极具流体感。
  - **歌单与曲目列表 (TrackRow)**：
    - 当前播放歌曲指示由硬切升级为动态平滑发光渐变。
    - 活跃曲目左侧新增滑动锁定光条指示器（Sliding Cursor）。
    - 列表根据播放状态自动平滑居中滚动聚焦当前曲目。
  - **全屏播放详情页 (NowPlayingOverlay)**：
    - 歌曲标题与音频规格标签支持横向丝滑滑动。
    - 封面艺术图支持柔光交叉渐变与微缩动效。
    - 播放队列面板（QueuePane）支持选中态平滑呼吸高亮与自动滚动定位。

- **曲目与歌单智能音量记忆 (Smart Per-Track & Playlist Volume Memory)**：
  - **解决曲目响度不一痛点**：听古典/B站钢琴类较小声音的曲目调大音量后，换回流行歌曲时自动降低，不再震耳。
  - **单曲与歌单专属音量记忆**：调节音量时自动记忆当前单曲及所在歌单的首选播放音量，并在切歌时平滑自动恢复。
  - **多平台安全持久化**：Android 与 Desktop 平台均支持自动保存记忆，跨会话无需重复调节；播放界面新增精确音量百分比显示。
