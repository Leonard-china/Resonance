# Resonance v0.3.1 (v3.1)

## 重点功能与保真音质升级

- **独立前级增益校准与保真软限幅 (Loudness Calibration & Pre-Amp Gain)**：
  - **绝不篡改系统全局音量**：完全剥离对 Android 系统全局媒体音量的干扰。无论如何调节曲目响度，退出应用或切换后台时，手机全局音量保持原样。
  - **动态压缩与软限幅保护 (DSP Soft Limiter)**：
    - 结合 ExoPlayer 音频流软衰减与 Android 原生 `LoudnessEnhancer` 动态压缩限幅 DSP，提供 **-12.0 dB 至 +12.0 dB**（步长 0.5 dB）高精度前级增益。
    - 针对 B站钢琴曲、古典乐等微弱音源，在大幅提亮听感响度的同时彻底避免数字削波失真与爆音破音，实现纯净保真。
  - **专属【🎚️ 响度增益校准】控制面板**：
    - 在全屏播放详情页顶部工具条新增一键展开/收起的校准模式切换按钮。
    - 展开后提供直观的滑动条与常用增益快捷键（`-6 dB`、`0 dB`、`+3 dB`、`+6 dB`、`+9 dB`），实时听感调节。
  - **曲目级智能本地记忆与无感应用**：
    - 校准的增益数据自动绑定曲目唯一标识并在本地持久化存储。
    - 切歌与后台播放时自动即时加载该曲目的专属增益，不同响度曲目无缝衔接。
