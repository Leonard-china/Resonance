# Resonance v0.3.2 (v3.2)

## 重点功能与音量统一方案全面落地

- **全自动工业级动态响度均衡 (Automatic Loudness Normalization)**：
  - **EBU R128 流媒体标准参考电平 (-14.0 dBFS)**：
    - 针对 B站钢琴曲、弱音源、古典乐录音电平低（往往低至 -24 ~ -30 dBFS）的痛点，底层自动检测计算音轨平均声压与动态峰值。
    - 遇到弱音源自动平滑补偿前级增益（最高达 +14 dB），遇到声压饱满的流行音乐自动平稳拉平。
    - 结合 Android 硬件 DSP `LoudnessEnhancer` 动态压缩与高保真软限幅（Soft Limiter），彻底杜绝削波失真与爆音破音，声音饱满通透。
    - **完全解放双手**：手机物理音量只需固定在常用舒适档位，切歌与跨歌单播放全程响度恒定，再也不会被突如其来的大音量轰耳。

- **专属【物理音量校准模式】(支持侧边按键无感记忆与自动复原)**：
  - **基于日常按键习惯的智能学习**：
    - 在播放详情页点击【开启物理音量校准模式】后，用户可直接按手机侧边的**硬件物理音量按键**调节到当前曲目最舒服的声音。
    - 播放界面实时显示物理音量档位与计算出的相对振幅增益（$\Delta \text{dB}$）。
    - 点击【保存并还原手机音量】（或切歌）时，应用**永久记忆该曲目专属振幅**，并**瞬间将手机系统全局音量自动还原到原本的标准档位**！
  - **内部音频管道精准重放**：
    - 下次播放该歌曲时，应用直接在内部音频解码管道注入该专属增益，完全忽略手机外部系统音量，且关闭应用后手机系统音量毫发无损。
    - 提供【重新校准】与【清除恢复自动均衡】一键操作。

- **音频渲染管线重构 (Master Volume & DSP Decoupling)**：
  - 彻底解耦 ExoPlayer 内部主音量控制与前级增益，避免多通道增益互相覆盖或竞争，保证全场景听感精确稳定。
