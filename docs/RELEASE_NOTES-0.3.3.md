# Resonance v0.3.3 (v3.3)

## 体验与质感全面升级

### 1. 彻底解决歌单 ⟷ 歌曲页面切换的割裂感（原生 3D 层级视差与流体弹簧转场）
- **多层级空间景深呈现**：
  - 打开正在播放页面时，底层的歌单列表界面优雅后撤（$scale: 1.0 \to 0.955$，轻微向下视差位移并自动柔化为圆角卡片）。
  - 半透明天鹅绒黑调幕布（Scrim）平滑渐显，营造自然沉浸的层次景深。
- **物理卡片感全面强化**：
  - 歌曲页面顶部赋予 $28\text{dp}$ 弧度圆角、高透磨砂光感上边缘（Specular Highlight Rim）以及深度立体阴影（Ambient Shadow）。
  - 顶部集成轻奢半透明水滴抓手条，支持丝滑下拉阻尼回弹手势关闭。
- **Apple Fluid 阻尼弹簧动力学**：
  - 替换原有的线性减速曲线，采用定制非线性阻尼弹簧（$\text{stiffness} = 360f, \text{dampingRatio} = 0.94f$），推入与滑出温润丝滑、浑然一体。

### 2. 全新【小巧精致流体高保真歌曲进度条】（Exquisite Scrubber）
- **极简纤细轨道与动态触觉扩散**：
  - 静止待机状态轨道仅 $3.5\text{dp}$，视觉纤巧雅致，与封面及界面浑然天成。
  - 用户按下或拖拽试听时，轨道与旋钮通过动画即时放大（轨道至 $5\text{dp}$，旋钮至 $14\text{dp}$ 并扩散 Primary 发光光晕），触控交互感充盈。
- **珠宝级珍珠光感旋钮**：
  - 纯白核芯，外嵌高对比立体主色光环与微投影，彻底告别原生粗大笨拙的系统 Slider。
- **等宽制表数字时间戳**：
  - 采用 Tabular Figures 等宽数字排版，避免秒数跳动时的文字左右晃动抖动；拖拽时当前进度时间高亮提示。

### 3. 全局按键质感重塑（告别扁平贴图感，微拟物与透光触感全面落地）
- **核心大播放键（Tactile Play/Pause）**：
  - $68\text{dp}$ 饱满外形，多层高光流体渐变与顶部 $1.5\text{dp}$ 镜面切边高光反光板。
  - 动态果冻级弹性物理反馈（按压深度可达 $0.88$，回弹自带微颤震感），$12\text{dp}$ 主题环境光漫反射投影。
- **切歌按钮（Tactile Skip Dials）**：
  - 上一首 / 下一首告别裸露单薄的矢量图标，升级为 $52\text{dp}$ 磨砂透光玻璃圆盘底座，带有物理立体倾斜镜面描边与按压动效。
- **随机 / 循环微胶囊按键（Tactile Mode Buttons）**：
  - 激活状态呈现轻奢微光胶囊药丸与呼吸光点标记，未激活状态呈现优雅半透磨砂玻璃质感。
- **顶部操作栏按键与收藏红心**：
  - 返回、更多菜单采用磨砂玻璃小圆钮；收藏红心点亮时绽放宝石红（`#FF4766`）外发光光晕与心跳弹性动效。
- **音量滑块与倍速胶囊**：
  - 底部音量条同步升级为超纤小巧流体滑槽，倍速按键采用微晶胶囊切片。
- **底部 Mini 播放栏按键联动**：
  - MiniPlayer 播放键与切歌键全线换装微拟物透光质感按键，随处触摸皆有质感。
