# Resonance v0.3.5

本版修复音量增益命令、快速切歌竞争和配置并发写入，并完善整曲响度分析、播放状态恢复与大曲库搜索。

- Android 显式向 MediaController 授予增益和主音量命令，校验命令返回结果。音频增益改为 Media3 PCM 处理器，支持正/负增益、192 ms 平滑变化和软限幅；主音量单独控制。
- Android 后台服务在自动切歌时读取该曲目的音量和增益，Activity 关闭后仍生效。
- Android 与 Windows 使用 FFmpeg 对完整音轨做 R128/BS.1770 响度分析，目标为 -14 LUFS，并按 -1 dBTP 的真实峰值余量限制自动增益，保留原录音动态。旧 RMS 抽样缓存自动失效；失败和静音结果不写入成功缓存。
- Windows 改用 FFmpeg 解码与 Java Sound PCM 输出，实际应用数字前级增益，避免播放器音量上限吞掉正增益；支持暂停、跳转、变速和错误反馈。
- 播放音频任务由独立状态对象管理。切歌取消旧任务，所有异步写回检查请求版本；用户手动修改音量/增益不会被晚到的读取或分析覆盖。
- 保存当前歌曲、队列、进度和歌单。冷启动恢复为暂停状态；Android 后台仍播放时重新连接现有会话。
- 曲库搜索在后台建立可复用的文本与拼音首字母索引，输入短暂去抖，并缓存歌曲合并、收藏和专辑/歌手分组结果。
- 修复打开歌单时详情内容与原列表重叠：转场区域裁剪、动画期间使用不透明页面底层，并在返回时保持详情页位于上层。保留 280 ms 推入/返回动效；减少动态效果时采用依次淡出/淡入。
- 配置写入按用户操作顺序串行执行；连续滑动音量合并待写值。两端曲库读改写事务加锁，托管曲库使用原子替换与上一有效版本备份，Android 歌单增加备份恢复。
- 版本只由 version.properties 定义，界面版本常量由构建生成；普通构建不再自动升版。增加 GitHub Actions 校验以及发布产物/校验值生成脚本。
