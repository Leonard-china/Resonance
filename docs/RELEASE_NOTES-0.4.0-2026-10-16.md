# 2026-10-16 — 0.4.0 优化构建：流畅切换、任务列表、专辑封面与同步歌词

本次按用户要求完成优化并构建 Android / Windows 发布版，保持 `versionName=0.4.0`、`versionCode=23`。它是 10 月 16 日的本机优化构建，GitHub 上 10 月 15 日已发布的 `v0.4.0` 仍为原始产物。本次未要求提交或上传，不替换已有 GitHub Release。

## 本次变化

- 恢复歌曲/歌单/专辑/歌手的轻量切换动画；保留各自浏览位置，进入歌曲页不自动长距离滚到当前歌曲。
- 完整播放器改用固定尺寸图层过渡，减少展开时背景重绘及环境光重组。
- 主导航第二项改为音乐助手，搜索保留在音乐库右上角；助手页隐藏迷你播放器。
- 每日推荐固定为歌单页第一项，未开启时点击设置，开启后进入独立推荐页面。
- B 站下载歌曲自动尝试真实专辑封面；支持既有下载批量匹配、单首强制匹配及自定义，未命中保留视频封面。
- 新增持久任务列表，记录下载、封面、歌词等步骤，可取消并单独重试媒体步骤。
- 修正同步歌词检索和播放位置；纯文本明确显示类型。可主动上传音频到百炼 Paraformer 生成同步歌词，结果缓存复用，语音秒数预算独立于聊天 Token。

## 使用

音乐库右上角和音乐助手中均可打开任务列表。已有下载歌曲的封面可在任务页批量匹配，单曲可从完整播放器菜单操作。

同步歌词生成需要在设置配置百炼语音 Key（或复用已配置千问 Key），默认北京地域接口。点击生成前会提示上传和按时长计费，默认月上限 60 分钟、单首最多 30 分钟。失败/取消可能也被供应商计费，本机按整曲时长保守预留用量；播放已有缓存不重复调用。自动推荐/下载不会自动调用收费音频识别。
