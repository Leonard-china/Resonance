# 2026-10-15 — v0.4.0：音乐助手、B 站音频、智能推荐与悬浮歌词

版本：**0.4.0 / versionCode 23**。本次提供 Android Release APK（Android 8.0 / API26 及以上），包名 `com.resonance.player`；Windows 功能源码同步更新，本次未生成 Windows 安装器。

## 主要更新

- 音量平衡简化为一个开关，新增独立详细说明页，统一播放器主音量。
- 移除设备/LAN/二维码同步与酷狗歌单链接导入，保留携带音频、封面、信息的歌单文件导出/导入；修复 FLAC 等原音频类型误标。
- 文件夹转换增加阶段、进度、取消和超时，保留源文件与已完成结果。Android 支持 KGMA，KGG 仍需 Windows 本机密钥转换。
- 修复列表缺封面的内嵌图片回退，限制大图解码/缓存；减少歌单与歌曲标签切换时的重叠绘制。
- 新增 B 站视频音轨导入，支持 BV、链接、分 P、自定义歌名/歌手/专辑/封面及加入歌单。
- 新增多模型音乐助手：通义千问、DeepSeek、豆包和自定义兼容接口，可分别选择文本与视觉模型；支持长截图 OCR、曲库/歌单管理和自动找源下载。
- 新增 AI 推荐：自定义间隔、数量、前台或后台执行，自动下载；收藏或加入自建歌单保留，未保存的临时推荐在下一批成功时清理。
- 新增 Windows/Android 后台悬浮歌词和自定义目标语言翻译，支持中文译英文等方向、双语显示与译文缓存。
- 改进信息补全匹配、逐首保存和失败处理，移除歌曲栏常驻的缺失信息计数。

## 使用与升级

使用现有正式签名构建；签名兼容验证结果见 [发布记录](changes/2026-10-15-13-release-0.4.0-android.md)。安装正式 APK 可保留原正式版数据；Debug 包使用不同包名，不会自动迁移其数据。

在设置中填写自己的 API Key、模型和地址，分别指定音乐管理与截图识别模型。推荐默认关闭，后台执行受 Android 调度限制；桌面歌词需要系统悬浮权限。音量详细说明在独立页面。

**点“不喜欢”会立即删除对应音频、取消收藏并移出所有歌单，即使此前已保存；原因可以跳过。** 下一批推荐仅清理未收藏、未加入自建歌单的临时曲目，正在播放时延后；新批总失败时保留旧批。

## 已知限制

- B 站可能要求官方登录/验证；当前开发网络返回 HTTP412，真实账号在线下载尚未验通。可在设置填写自己的 Cookie，受限时显示原因。
- 没有真实模型 Key，收费模型服务未进行在线验通；工具/缓存/截图/推荐等由可注入模型和音源回归覆盖。Token 预算和供应商缓存不等于人民币账单保证。
- Android KGG 不支持；系统后台执行不是精确闹钟。API32 回归不代表所有国产 ROM/API36 后台策略。
- AI 元数据工具修改曲库覆盖值；新下载 MP3 会真实写入标签与封面。旧 DeepSeek 明文配置为兼容可能保留。

功能具体修改见 [变更索引](README.md)，实现与排查见 [开发说明](DEVELOPMENT.md)。本次构建、验签、清单和 GitHub 交付见 [发布记录](changes/2026-10-15-13-release-0.4.0-android.md)。
