# 2026-10-16 — v0.4.1：AI 多会话历史、音频对齐歌词、持久任务列表与动效体验深度优化

版本：**0.4.1 / versionCode 24**。本次提供 Android 签名正式版 APK（Android 8.0 / API 26 及以上，包名 `com.resonance.player`）与 Windows 64位独立安装包（`Resonance-0.4.1.exe`）。

## 主要更新

1. **AI 音乐助手多会话隔离与模型溯源**：
   - 支持像常规 AI 软件一样创建多会话与管理历史记录（上限 30 个），首条消息自动提取生成标题。
   - **Token 节约机制**：多会话完全隔离本地存储，切换与新建 **0 Token 消耗**；单次请求仅提取当前会话最近 16 条上下文，杜绝跨会话 Prompt 膨胀。
   - 助手回复气泡顶部明确标注“回复自 XXX”，顶栏副标题常驻显示活跃模型。
   - 常用模型推荐 Chip（千问、DeepSeek、豆包主流模型）一键填入，提供“恢复默认地址与模型”操作防止误删。
   - 适配移动端软键盘（IME）弹起与新消息到达平滑自动滚动到底部。

2. **音频时间戳同步歌词生成（百炼 Paraformer）**：
   - 针对缺乏时间轴的本地歌曲或纯文本歌词，支持一键上传音频至阿里云百炼语音大模型，根据人声时间戳生成逐句同步歌词。
   - 识别结果写入本地持久缓存，后续播放直接读取，无需重复计费；语音秒数预算独立于聊天 Token，并支持配置每月处理上限。

3. **持久化任务中心与按步重试**：
   - 无论从 B 站导入还是批量封面匹配，所有任务均持久化至本地任务日志（重启不丢）。
   - 清晰记录下载、转码、封面、歌词各阶段进度；针对下载成功但网络异常导致封面或歌词失败的曲目，可一键仅重试媒体步骤。

4. **真实专辑封面智能匹配**：
   - 导入音乐或批量补全时，优先检索正版高清专辑封面（QQ 音乐 / iTunes 正版目录优先匹配）；
   - 检索未命中时自动平滑回退至原视频高清封面，亦支持用户手动选取自定义封面。

5. **全屏沉浸播放器与流体微光重组优化**：
   - 灵动岛展开改用固定尺寸图层平滑过渡，大幅减少展开与收起时的重绘开销与环境光重组抖动。
   - 顶部栏常驻桌面悬浮歌词触觉切换按钮，带激活微光反馈。

6. **桌面悬浮歌词系统权限反馈（Android）**：
   - Android 端切换桌面悬浮歌词时实时检测系统权限，未授权时弹出引导对话框并提供「前往设置」直达系统悬浮窗权限授权页。

7. **界面过渡黑边闪烁修复与独立关于页面**：
   - 页面切换过渡动画启用满屏约束与硬边界裁剪，迷你播放器平滑伸缩展开与收起，彻底消除切页时顶部状态栏黑边闪烁。
   - 工具页彻底拆分“设置”与“关于 Resonance”，新增独立专有关于页，全面解析 Local-First 本地优先架构、九大核心特性与使用技巧。

## 使用与升级

- **Android**：使用正式签名密钥签名，可直接覆盖安装升级，曲库、歌单、设置及历史会话数据完整保留。
- **Windows**：运行 `Resonance-0.4.1.exe` 安装，内置完整执行环境与 FFmpeg。
- **数据自治**：应用保持完全本地优先（Local-First），不设云端账户，所有音频、歌词、封面及会话历史均安全保存在用户设备本地。
