# 2026-10-17 — Resonance v0.4.6：本地歌单 OCR 与完整歌名导入

适用平台：Android / Windows。版本：`0.4.6 / 29`。

## 主要更新

- 歌单截图默认使用本机 OCR：Android、Windows 各自在设备上识别，模型随安装包内置，无需识图 API Key 或额外服务。
- 设置中保留“本地 OCR / 云端 API”切换，聊天和音乐管理的 API 配置独立保留；本地识图不会自动切到收费 API。
- 长截图逐片识别并去重，OCR 模型会话只在识别期间加载，结束、失败或取消后关闭。
- 截图歌名或歌手带省略号时，先核对本地曲库和公开歌曲信息；确认后以完整名称搜索音源、写入新 MP3 标签和曲库。存在歧义或无法确认时列出未完成项。
- 官网同步新版双端安装包、更新公告与详细软件介绍。

## 使用与升级

直接安装新版以保留曲库、歌单、模型配置和教程进度。设置 → AI 音乐助手 → 歌单截图识别，选择本地 OCR 或云端 API。老配置没有识别模式时默认本地 OCR，原 API 地址、模型和 Key 不删除。

本地 OCR 的图片识别无需联网；完整歌曲信息查询、音源搜索和下载仍需联网。聊天、翻译、生成同步歌词等 API 功能维持各自的网络和计费规则。模糊图片、旋转照片和复杂排版可能无法可靠解析；可手动改用云端 API。已有曲库不进行批量改名或重新编码。
