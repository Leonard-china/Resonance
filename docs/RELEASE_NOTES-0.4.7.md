# 2026-10-17 — Resonance v0.4.7：歌源生态扩展、推荐赞踩反馈、存储空间管理与页面手势交互

适用平台：Android / Windows。版本：`0.4.7 / 30`。

## 主要更新

- 歌源生态支持：内置 QuickJS 引擎，支持导入运行 MusicFree 核心歌源插件，提供歌曲搜索、多音质流媒体播放与下载。
- 音频与封面溯源：记录并展示下载曲目的来源平台与专辑封面出处，支持批量补全并清晰标注录音室版本候选评分。
- 每日推荐体验升级：推荐歌曲跨会话去重与默认 7 天滚动冷却，支持单曲或批量直接保存至自建歌单；换批智能保护已收藏与入单曲目。
- 推荐赞踩与评论反馈：推荐卡片支持可撤销的点赞、点踩与最多 500 字本地评论，真实偏好参与后续本地选曲与种子权重计算。
- 应用下载与空间管理：独立统计托管音频占用空间，支持精确重复文件识别、清理前置预览与释放已保存音频，提供文件占用删除失败安全回滚。
- 单曲歌词校准与界面适配：支持 ±600 秒（步长 500ms）单曲歌词偏移双向微调与原子持久化；优化手机端窄屏、长标题与双语歌词排版。
- 音乐助手指令扩展与离线帮助：新增播放控制与页面导航执行工具；内置常见问题离线帮助检索，直接复用教学说明而不调用云端模型。
- 全局左右滑动手势：主导航栏目、曲库分类与播放器面板支持左右手势拖动流畅切页，结合 24dp 边缘防误触与首末页阻尼拦截。

## 使用与升级

直接安装新版覆盖旧版，原有曲库、自建歌单、模型配置、离线教程进度及歌词偏移将完整保留。

- **歌源管理**：通过“设置 → 歌源管理”导入本地或在线歌源脚本，可对各源进行启停与卸载。歌源网络请求严格受限公网 HTTPS，隔离内网与敏感权限。
- **推荐反馈**：在推荐卡片中点击“点赞”提升喜好权重，点击“踩”降低相关歌手/专辑权重，点击“评论”输入个人心得（纯本地保存），帮助推荐算法更懂你的音乐品味。
- **下载空间管理**：“设置 → 下载与空间”可查看托管音频用量；“释放已保存音频”仅移除本地文件以节省空间，曲目与歌单关系完整保留，后续联网可一键重新下载。
- **歌词校准**：在播放器歌词界面轻触校准按钮，可按 500ms 步长提前或延后歌词，修改即时生效并自动持久化。
- **手势操作**：在内容区域左右横滑即可快速在“歌曲 / 歌单 / 专辑 / 歌手”或主导航页面间切换，滑动受速度与距离双阈值保护，不影响列表垂直滚动与系统返回手势。
