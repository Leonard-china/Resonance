# 2026-10-17 — Resonance v0.4.8：滑动换页跟手动画、动效流畅度优化与内置三大主流免配置歌源

适用平台：Android / Windows。版本：`0.4.8 / 31`。

## 主要更新

- 滑动换页跟手动画：引入高帧率硬件加速跟手位移（graphicsLayer），内容随手指横向拖动实时平移，结合首末边界橡皮筋阻尼拉伸与未达阈值物理弹簧回弹。
- 曲库标签流体过渡：曲库四标签（歌曲/歌单/专辑/歌手）升级为 120dp 饱满平移距离、0.15~1.0 透明度淡入与 280ms 流体减速贝塞尔动效，空间方位感明确连贯。
- 动效渲染流畅度调优：优化主导航与工具二级页面切换的动态裁剪开销（SizeTransform），消除逐帧重测重排，保障 60/120fps 满帧如丝顺滑。
- 内置三大主流公网歌源：开箱即用内置网易云音乐、酷我音乐、酷狗音乐 3 款核心公网歌源，原生支持歌曲搜索、多音质音频直链下载、专辑大图与同步歌词。
- 歌源开箱即用与一键恢复：双端原生启动自动预置并启用内置歌源，告别用户手动搜寻配置插件；歌源管理页提供“恢复内置歌源”一键重置按钮。
- 官网极速下载通道集成：官网下载页接入国内 123 云盘不限速直链分发与多线路容灾，彻底释放国内下载速度并不抢占国际出口带宽。

## 使用与升级

直接安装新版覆盖旧版，原有曲库、自建歌单、已导入自定义歌源、模型配置、离线教程进度及歌词偏移将完整保留。

- **滑动换页**：在屏幕内容区域左右横滑即可实时跟手平移；在“歌曲 / 歌单 / 专辑 / 歌手”或主导航间滑动时伴随平滑流体进出场动效。滑动受速度与距离双阈值保护，不影响垂直列表滚动与系统返回手势。
- **开箱即用歌源**：安装启动后自动载入网易云音乐、酷我音乐与酷狗音乐三大常用公共歌源，普通搜歌、AI 助手找歌及每日推荐均可直接选用；若误删可前往“工具 → 歌源”点击“恢复内置歌源”随时还原。
- **极速下载体验**：国内用户可直接在官网通过绿色推荐通道（123 云盘免流量极速直链）享受数十兆/秒的高速下载。
