# 2026-10-17 — Resonance v0.4.9：歌源网络协议放开、多候选智能回退机制与二级页面转场黑边消除

适用平台：Android / Windows。版本：`0.4.9 / 32`。

## 主要更新

- 歌源网络协议优化：支持公网 HTTP/HTTPS 音频直链与高达 5 次安全 302 重定向跟随，严格守护私网 DNS 级 SSRF 防护，彻底解决网易云、酷我等合法外链下载播放受阻。
- 多候选智能回退机制：当单曲在首选歌源获取失败或因平台版权保护返回 10 秒试听时，自动跨源多候选智能回退重试，杜绝因单源失败导致整批推荐中断。
- 试听防假与解码增强：内置酷我歌源增加 VIP 试听标记拦截，提早过滤短音频假资源；解除酷狗强制协议替换；双端封面解码全面支持 HTTP 链接。
- 消除转场黑边闪烁：全局禁用二级页面进入/退出的尺寸过度裁切（SizeTransform clip=false），彻底消除从“工具”进入“设置”时屏幕顶部的黑边闪烁。
- 沉浸式透明系统栏：Android 端统一配置透明自适应状态栏与导航栏（SystemBarStyle.auto），窗口底层与主题深色底色无缝统一，杜绝转场边缘撕裂。

## 使用与升级

直接安装新版覆盖旧版，原有曲库、自建歌单、已导入自定义歌源、模型配置、离线教程进度及歌词偏移将完整保留。

- **歌源稳定性提升**：网易云与酷我内置歌源现在能正常解析 CDN 重定向与 HTTP 音频流；遇到 VIP 版权试听限制的曲目（如《夜曲》）时，系统会自动尝试其他歌源及 B 站音频候选，确保每日推荐与助手找歌顺利完成。
- **顺滑沉浸视觉**：从“工具”点击打开“设置”或其它二级页面时，页面完整自右侧平滑推入，顶端状态栏与内容背景连贯无撕裂，不再出现任何黑边闪烁。
