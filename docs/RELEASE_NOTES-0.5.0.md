# 2026-10-17 — Resonance v0.5.0：体验优化集大成、统一搜索试听、截图核对、任务重试、离线重定位与双端原生睡眠定时

适用平台：Android / Windows。版本：`0.5.0 / 33`。

## 主要更新

- 统一搜索与候选试听：整合本地曲库与在线多歌源搜索，单曲提供 30 秒临时安全试听与同歌跨源换来源，离页或切歌即时清理临时音频。
- 截图歌单核对与导入：本地 OCR 与云端截图识别后先预览完整歌单，支持逐首勾选、在线编辑修正歌名歌手，确认后再入库与查找下载。
- 任务分组与批量重试：按单次导入或整理聚合多级任务，清晰展示各歌曲阶段进度；支持一键批量重试未完成的媒体步骤，跳过已完成项。
- 离线恢复与文件重定位：精准区分未下载、文件丢失与失效状态；支持重新定位本地已有音频并保留原始 ID、收藏及自建歌单归属。
- 双端原生睡眠定时：支持 15/30/45/60 分钟倒计时与播完当前歌曲停止；Android 端由播放服务后台接管，曲终暂停抑制队列推进。
- 推荐历史与反馈管理：新增独立推荐历史与个人反馈管理页，点赞、踩和个性化偏好标签独立存储与筛选，支持撤销旧拒绝。
- Windows 键盘全局导航：支持 Ctrl+F 快速聚焦搜索、空格键播放暂停、Ctrl+方向键切歌，以及 Esc 逐级退出多选、关闭播放器与返回。
- 自动推荐网络限制：支持限制仅在不计费网络下执行自动推荐与后台下载，推荐界面清晰显示网络等待状态与下次到期时间。
- 视口覆盖与消除黑边：采用固定视口与每页主题画布覆盖，禁止非必要尺寸变换插值，窗口底色动态跟随主题，彻底杜绝转场边缘闪烁。

## 使用与升级

直接安装新版覆盖旧版，原有曲库、自建歌单、已导入自定义歌源、模型配置、离线教程进度、历史反馈及歌词偏移将完整平滑保留。

- **搜索与试听**：搜索页面默认聚合本地与在线歌曲，输入关键词后点击“搜索在线歌曲”即可获取多源候选，支持 30 秒片段试听与快速换源。
- **截图歌单二次核对**：导入歌单长截图后，系统会展示弹窗列出识别出的全部歌曲，用户可编辑歌名歌手、去除误识别曲目后再确认下载。
- **离线音频管理**：曲库与歌单中新增离线歌曲标识，点击可一键重新下载或在本地文件中重新定位关联，不改变歌单与收藏关系。
- **睡眠定时**：在播放控制与设置中支持选择定时停止（15/30/45/60 分钟或播完当前歌曲），方便睡前聆听且不消耗额外电量。
