# 2026-10-26 — Resonance v0.6.0：AI 语义找歌、曲库智能管家、实时消音伴奏、本地音频特征与音乐品味画像双端正式版

适用平台：Android / Windows。版本：`0.6.0 / 34`。

## 主要更新

- 自然语言语义找歌：曲库搜索栏新增「AI 语义」模式，支持自然语言意图识别（场景、情绪、曲风、BPM 区间与关键语义），精准联想召回本地曲库与在线歌源，每首歌均提供高亮智能匹配理由。
- 本地曲库智能管家：工具箱新增「曲库智能管家」，支持一键全库体检、智能清理前缀垃圾字符（如 `kw_`、`320k_`、`【无损】`）、从标题分离歌手、规范未知专辑，并自动分析同名不同版本与音质冗余，提供安全预览确认机制。
- 实时伴奏消除（K歌模式）：在双端原生 PCM 播放管线实现立体声中置人声消除与 160Hz 低频保护算法，可在播放器下拉菜单中一键开启「伴奏模式」，零额外延迟、低 CPU 开销且不占用额外存储空间。
- 本地音频特征提取：实现纯本地轻量 DSP 节奏分析算法，毫秒级快速提取整曲 BPM（55~210 BPM）与能量等级（10~99），并持久化缓存于本地特征库，为节奏选歌与智能推荐提供特征支撑。
- 六维音乐品味画像：基于本地收藏、播放频次与反馈历史，自动计算流行敏锐、复古情怀、小众探索、情绪共鸣、节奏活力、流派多样六维指标，使用 Compose Canvas 动态绘制六边形品味雷达图，并提炼专属听歌性格（如“光影留声机”、“深夜白日梦想家”）。
- 一键生成精美分享海报：在歌单详情页与品味画像页提供「生成海报」，支持极光暗夜质感海报渲染、精选曲目与雷达图拼贴展示，支持一键复制文案与海报分享。

## 使用与升级

直接安装新版覆盖旧版，原有曲库、自建歌单、已导入自定义歌源、模型配置、离线教程进度、历史反馈及歌词偏移将完整平滑保留。

- **AI 语义找歌**：点击曲库右上角搜索，在搜索栏下方选择「AI 语义」，输入如“适合雨天的治愈慢歌”或“140 BPM 跑步燃歌”即可体验。
- **曲库智能管家**：在“工具”页选择「曲库智能管家」，点击“一键全库体检”，查看标签清洗建议与重复版本，勾选后点击批量应用即可规范化曲库。
- **伴奏模式**：展开正在播放界面，点击右上角更多菜单（三个点），选择「伴奏模式 (人声消除)」即可实时消除中置人声并保留低音律动。
- **音乐品味画像**：在“工具”页选择「音乐品味画像」，可查看专属六维雷达图与性格标签，点击右上角「生成海报」可预览并复制分享卡片。
