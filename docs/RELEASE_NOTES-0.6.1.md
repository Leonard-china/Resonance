# 2026-10-27 — Resonance v0.6.1：画廊展台立体原生 UI、轻量动效与全域交互打磨双端正式版

适用平台：Android / Windows。版本：`0.6.1 / 35`。

## 主要更新

- 18 号画廊展台立体原生设计：方正小圆角装裱封面、实体底部展架与右下定向柔和投影，搭配白色播放操作台，打造沉静立体的画廊陈列质感。
- 实体播放控制台与触觉交互：主播放按键采用轻下沉与微阴影实体质感，滑块配备 48dp 无障碍触控判定与原生进度语义。
- 呼吸感全域导航与页面层级：曲库与播放器分栏采用青绿下划线与文字强调，设置/工具图标使用小台面承载，歌词与队列表面提升不透明阅读质感。
- 轻量动效与全局动效偏好：集中 120/160/220ms 反馈响应，消除高频跳动与重组，全面适配「减少动态效果」系统偏好。
- 智能紧凑布局与绘制性能优化：小屏大字号下自动切换紧凑播放布局，光晕与阴影画刷缓存复用，动态状态收敛至绘制阶段。

## 使用与升级

直接安装新版覆盖旧版，原有本地曲库、自建歌单、AI 语义找歌模型、音乐品味画像及伴奏消除数据将完整平滑保留。

- **画廊展台封面**：每日推荐、歌单详情与全屏播放页中的专辑封面均采用画廊小圆角装裱与定向立体投影展架，带来视觉焦点与层次感。
- **实体操作台**：正在播放页的操作按键与音量滑块整合于微凸实体控制台，主播放键提供自然的触觉轻降反馈。
- **自适应紧凑模式**：在小屏或系统开启大字号时，播放页自适应切换为紧凑布局，保持封面展示与核心控制的平衡。
