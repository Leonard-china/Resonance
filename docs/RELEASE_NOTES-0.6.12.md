# 2026-11-14 — Resonance 0.6.12：修复睡眠定时器、智能补全和重复导入

## 主要更新

- 修复睡眠定时器和智能补全弹窗可能使应用无响应的问题。
- Android 从系统媒体库和文件夹导入同一份音频时只显示一次。已有歌单、收藏及播放位置继续可用，导入结果会区分实际转换和已入库文件。
- 「加入歌单」统一选择入口，支持搜索和新建歌单。视频来源歌曲可补全专辑封面，下载、批量补全和播放器使用统一的歌词查找流程。
- Android 调整下一首或播放队列时保留当前曲目、进度和播放状态。
