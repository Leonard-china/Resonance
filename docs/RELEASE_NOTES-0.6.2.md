# 2026-10-27 — Resonance v0.6.2：全面温润质感打磨、标志性波浪进度条与沉浸动效双端正式版

适用平台：Android / Windows。版本：`0.6.2 / 36`。

## 主要更新

- 标志性波浪进度条：全屏播放页采用柔和自然的波浪线条与珍珠质感旋钮，支持毫秒级拖动定位与平滑预览。
- 沉浸全屏播放体验：告别机械方正硬台，重塑 22dp 优雅专辑封面圆角与多层漫反射阴影，恢复 85% 灵动环境流光氛围背景。
- 悬浮胶囊迷你播放器：底栏迷你播放器进化为 18dp 悬浮胶囊形态，集成纤细进度指示与灵动切换动效。
- 统一现代温润卡片：歌单网格与各功能页全面升级为 14dp 雅致圆角卡片，剔除生硬底托与木质搁板结构。
- 触控与排版层级升维：全局播放控制按键呼吸悬浮，重构歌词预览纵向层次与触觉反馈，兼顾大字号与单手操作。

## 使用与升级

直接安装新版覆盖旧版，原有本地曲库、自建歌单、AI 语义找歌模型、音乐品味画像及伴奏消除数据将完整平滑保留。

- **标志性波浪进度条**：在全屏播放页中，进度条呈现自然柔和的正弦起伏波形，已播放部分为纯净鼠尾草绿，未播放部分为低对比浅灰绿，珍珠质感旋钮随进度跟手滑行。
- **22dp 悬浮专辑艺术**：剔除此前生硬的 2dp 直角与底架，封面自然悬浮在流体光晕背景之中，提供绝佳的视觉沉浸感。
- **18dp 胶囊迷你播放器**：悬浮于页面底部的迷你播放器，搭配 10dp 封面微缩图与顶部彩色细条进度指示，切歌平滑流畅。
