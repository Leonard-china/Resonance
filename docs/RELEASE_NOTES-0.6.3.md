# 2026-10-28 — Resonance v0.6.3：听歌时长统计、跨平台音效调校、取消Token限制与每日推荐未听保护双端正式版

适用平台：Android / Windows。版本：`0.6.3 / 37`。

## 主要更新

- 听歌时长与完播统计：自动精确统计单曲累计播放秒数、完播率与全库总听歌时长，并在歌曲来源与品味画像中直观展现。
- 跨平台专业音效预设：全屏播放与歌曲详情页新增原声、纯净人声、澎湃低音、现场流行、震撼摇滚、3D环绕声场及K歌消音预设实时切换，双端听感高度一致。
- 取消 Token 与预算上限限制：全面移除 AI 音乐助手单月 Token 消耗上限、余额预算拦截及输入截断限制，畅享无拘无束的智能选歌与对话。
- 每日推荐未听歌曲到期保留不换：每日定时推荐新增未听保护机制，到期时若当前推荐歌曲尚未播放收听，自动保留现有推荐不予强制轮换覆盖。
- 取消助手 16 轮工具调用步骤限制：放开 Agent 工具调用步数硬编码上限，支持长链路多步骤复杂音乐查询、过滤与曲库管理操作自如完成。

## 使用与升级

直接安装新版覆盖旧版，原有本地曲库、自建歌单、AI 语义找歌模型、音乐品味画像、伴奏消除数据及听歌统计将完整平滑保留。

- **听歌时长与完播统计**：在“歌曲详情”与“音乐品味画像”中即可查阅当前歌曲收听时长与今日总收听时间。
- **跨平台专业音效调校**：展开正在播放界面，点击控制栏“音效”胶囊或进入右上角菜单即可选择 7 款针对性调优预设。
- **AI 音乐助手体验跃升**：彻底摆脱 Token 与轮次束缚，支持长指令、多曲库综合调度与不间断交互。
