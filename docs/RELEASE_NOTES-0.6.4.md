# 2026-10-28 — Resonance v0.6.4：Mineradio 沉浸音乐舞台、端到端加密双人一起听与自适应封面氛围双端正式版

Resonance 0.6.4 正式版带来全新 Mineradio 风格沉浸式原生音乐舞台、唱片透视封面与大字歌词布局，新增自适应封面取色流动波浪氛围与切页跳跃回弹物理动效；上线完全去中心化的双人端到端加密「与朋友一起听」，支持剪贴板智能一键秒连与自然语言消息容错；并在 Android 16 与超大系统字号下提供全域安全边界防护。

适用平台：Android / Windows。版本：`0.6.4 / 38`。

## 主要更新

- Mineradio 风格沉浸式原生音乐舞台：透视封面、墨蓝黑冷灰质感、大字歌词舞台与悬浮控制台。
- 自适应封面取色与跳跃回弹动效：提取唱片主题色流动波浪底色，切页回弹动效与空曲库/助手欢迎引导。
- 双人端到端加密「与朋友一起听」：去中心化点对点直连，音频与播放进度实时秒级同步且不经中转。
- 极简一起听交互与剪贴板识别：自动识别邀请一键加入，自然语言链接容错提取与局域网一键秒建。
- Android 16 适配与大字号防护：系统栏动态避让，150% 字号与多种窗口比例下无遮挡无截断。

## 升级与数据兼容性

- **平滑兼容**：本次发布完全向后兼容旧版曲库数据库、用户自建歌单、历史听歌统计数据与本地偏好设置，无需迁移。
