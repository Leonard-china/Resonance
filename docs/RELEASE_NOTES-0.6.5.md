# 2026-10-29 — Resonance v0.6.5：全新播放队列深度管理、下一首播放置顶、曲库即时排序筛选与双语歌词舞台双端正式版

Resonance 0.6.5 正式版带来全方位的播放体验精细打磨：推出深度播放队列管理体系，支持一键定位当前歌曲、清空其他待播歌曲及自由调整播放顺序；引入广受期待的「下一首播放」插队置顶功能；曲库单曲列表新增列表内即时检索与按歌名、歌手、专辑、时长的多维排序及无损/缺失项快捷芯片筛选；对大字歌词舞台增加了「回到当前播放」悬浮复位与双语明暗层次微调，全面提升大曲库下的音乐管理与欣赏效率。

适用平台：Android / Windows。版本：`0.6.5 / 39`。

## 主要更新

- 全新播放队列深度管理：支持歌曲总数直观统计、一键定位当前播放、批量清空其他待播歌曲及队列上下顺序微调。
- 「下一首播放」置顶插队：在曲库歌曲菜单、搜索列表与队列中一键置顶设为下一首播放，不破坏主队列连续性。
- 曲库即时搜索与多维排序筛选：曲库单曲列表内嵌即时快速过滤搜索框，支持按歌名/歌手/专辑/时长双向排序及无损/高品质/缺封面/缺元数据状态芯片筛选。
- 双语歌词舞台交互与动效打磨：滚动离开时提供悬浮「回到当前播放」快速复位按钮，歌词翻译层级明暗对比精细优化。
- 多端架构与高星实践深度融合：借鉴椒盐音乐与 Poweramp 等主流开源播放器工程经验，强化 Android 12-16 模拟器与真机渲染稳定性。
