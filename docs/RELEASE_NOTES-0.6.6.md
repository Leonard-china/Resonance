# 2026-11-05 — Resonance v0.6.6：三端原生播放、连续歌词与曲库安全修复

适用平台：Android / Windows / Linux x86_64。版本：`0.6.6 / 40`。本次更新此前未公开的0.6.6草稿，三端重新构建，不复用旧安装包。

## 主要更新

- 更新手机与桌面的原生播放界面，加入播放条到完整播放页的展开、跟手收起和回弹；封面、歌词与队列保持连贯。
- 恢复封面页的同步歌词预览和当前句高亮；纯文本缓存不再阻断同步歌词检索，改进连续跟随及大字体、小窗口下的控制可达性。
- 桌面支持多选音乐文件或目录、整窗拖入及直接导入 `.resonance` 歌单包；保留源音频、导入进度和取消能力。
- 歌单包导入先完整校验曲目与歌单，增加引用、清单和磁盘预算；运行期提交失败会尝试恢复被替换的文件与元数据。
- 暂时离线的曲目继续保留在曲库、收藏和歌单中，编辑其他歌曲不再丢失离线记录。
- 助手删除音频必须先展示具体文件并由用户在本机确认；询问、解释和否定不直接执行删除，旧确认不能重复使用。
- 智能清理保留Live、Remix、伴奏等录音版本，默认不选择删除；整批明细一次确认，取消不删，失败条目保留可重试。
- 删除音频不再误删共享或用户选择的封面；权限失败明确报告，批量删除只移除实际成功条目。
- 改进桌面配置备份恢复、Android设置保存失败反馈，以及应用退出、快速切歌和持久化任务的边界。
- 修复Android导出选项卡顿，导出过程显示处理状态、真实保存位置与文件名；按歌单命名并保留已有文件。
- Linux提供包含Java运行时的便携包及DEB安装包；Windows提供完整EXE安装包，Android提供正式签名APK。
- 修复Linux旧版FFmpeg的响度测量参数兼容，继续限制增益与峰值余量。
- 官网导航按最后一次点击提交，避免较慢的旧页面覆盖当前页面；更新新版介绍、界面预览与三端下载说明。

## 安装与升级

Android使用正式签名APK覆盖安装；Windows运行EXE安装包。Linux便携包完整解压后运行 `Resonance/bin/Resonance`，或在提供t64系统库的发行版安装DEB；Linux需要系统FFmpeg。不要只复制桌面包里的单个启动文件。

保留曲库、歌单与偏好格式，不自动清理用户音频。Linux凭据保护与Windows DPAPI不互通，换系统需重新配置账号。删除真实音频仍不可撤销。
