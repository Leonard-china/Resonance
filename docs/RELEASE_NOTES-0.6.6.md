# 2026-11-04 — Resonance v0.6.6：原生磨砂界面、Linux 桌面版与播放稳定性更新

适用平台：Android / Windows / Linux x86_64。版本：`0.6.6 / 40`。

## 主要更新

- 更新原生磨砂界面、封面氛围、桌面侧栏与设置分组，保留手机和桌面的原生播放流程。
- 增加 Linux x86_64 桌面发行包，包含 Java 运行时，使用系统 FFmpeg。
- 完善一起听的加密聊天、常听伙伴、队列控制与中继连接，改进断线和本地播放中断后的处理。
- 将听歌统计交给原生播放会话，改进偏好写入顺序、播放错误归属与加载／缓冲提示。
- 改进连续歌词跟随、真实歌源歌词回退及歌词空态；助手歌曲链接支持点播和追加队列。
- 内置歌源增至五个，增加 QQ／独立音乐来源并兼容 VPN DNS；收藏入口精简为歌曲数量。
- 隔离音量与音效原生弹窗的宿主模糊采样，避免独立窗口继续使用主窗口图层。

## 安装与升级

Android 使用正式签名 APK 覆盖安装；Windows 使用 EXE 安装包；Linux 完整解压便携包后运行 `Resonance/bin/Resonance`，并安装系统 FFmpeg。不要只复制桌面包中的单个启动文件。

保留原曲库、歌单和偏好格式；不迁移或删除用户音频。Linux 的凭据保护与 Windows DPAPI 不互通，换系统需重新配置相关账号。
