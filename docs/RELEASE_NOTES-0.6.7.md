# 2026-11-05 — Resonance v0.6.7：助手联网检索、原生回答与独立播放修复

适用平台：Android / Windows / Linux x86_64。版本：`0.6.7 / 41`。从本次固定源码快照重新构建三端正式包。

## 主要更新

- 音乐助手接入 DeepSeek 官方网页搜索和正文抓取，可查找播客与音乐资料，并引用实际返回的来源；需要当前使用已配置的 DeepSeek 官方连接，搜索和抓取独立计费，可在 AI 设置关闭。
- 助手回答使用成熟原生 Markdown 组件，支持标题、列表、加粗、可点击网页来源和文字选择；检索步骤可展开查看。
- 修复检索得到新结果仍被判定为无进展的问题；连续空结果或重复失败后最多生成一次最终文字答复，保留重复调用保护和取消能力。
- 同一错误不再重复显示三遍；模型空回复明确报错，本地执行失败不冒充模型回答。
- 移除一起听、房间、伙伴与远端同步入口，保留本机播放、曲库和队列；不自动清理旧房间数据。
- 修复自动切歌后音乐继续播放、按钮却显示暂停状态的问题，改善音频设备失败后的进度保留与重试。
- 歌词工具支持独立滚动，校准面板层级清晰；减少暂停／后台空闲开销并索引歌词时间戳。
- 截图歌单的待确认草稿、编辑与勾选可跨进程保留，确认前不下载或创建歌单。
- 支持批量预览和重新定位失效音频路径；接入本地 BPM 分析、来源校验缓存与节拍筛选。

## 安装与升级

Android 使用同签名正式 APK 覆盖安装，Windows 使用完整 EXE 安装程序。Linux 便携包完整解压后运行 `Resonance/bin/Resonance`，或安装 DEB；Linux 需要系统 FFmpeg，DEB 的具体系统依赖以本次实际产物为准。

保留曲库、歌单及偏好兼容，不自动删除用户音频。网页检索使用当前 DeepSeek 官方连接，代理或其他供应商的 Key 不会转发给 DeepSeek。网页内容不能授权下载、删除或改库；音频删除仍要求本机确认。

## 验证与限制

助手当前源码定向回归 78 项通过；此次发布的完整回归、三端构建、签名、产物校验和公开状态以[本轮发布记录](changes/2026-11-05-43-publish-0.6.7-harness-release.md)为准。

未用真实付费模型验证推荐质量；网页内容和服务可用性受服务商及来源网站影响。本轮实现网页资料检索，没有新增 RSS 订阅或播客流媒体播放，也不等同完整 DeepSeek Harness 的 shell／文件系统／桌面代理。设备、Windows 可见 GUI、全部 Linux 发行版、长时播放与性能范围在发布记录中逐项列明。
