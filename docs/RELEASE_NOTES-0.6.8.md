# 2026-11-06 — Resonance 0.6.8 音乐助手下载指引

本版为 Android、Windows 和 Linux 提供同一套音乐助手系统提示词。新版提示词补充了下载时的来源选择，下载指定歌曲时先搜索已安装歌源，找不到再尝试 B 站，同时要求减少重复追问。

- Android 使用 0.6.8 / 42，延续正式版签名。
- Windows 提供 EXE，Linux x86_64 提供便携包和 DEB。
- 下载和检索的实际结果取决于可用歌源、B 站内容和配置的模型。
