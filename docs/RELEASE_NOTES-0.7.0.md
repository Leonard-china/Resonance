# 2026-11-21 — Resonance 0.7.0 清岚播放器与歌词校准

适用于 Android、Windows 和 Linux x86_64，版本号为 `0.7.0 / 70`。

## 主要更新

- 播放器采用清岚浅色与深色主题。播放键和底部切换栏加入弹簧动效，沉浸歌词突出当前唱到的一句。
- 在同步歌词页点「校准」，可边听边看当前句，每次提前或延后 0.5 秒。生成、识别和翻译收进独立工具窗口，大字号下仍能操作播放和重置偏移。
- Android 修复部分文件系统下无法导入歌单包的问题。多选补全可以保存系统媒体库曲目的信息，并改进封面匹配。

## 从 0.6.12 升级时的功能变化

本版沿用 0.6.6 的功能分支，重新提供「一起听」入口。0.6.12 的离线曲目批量重新定位、加入歌单弹窗搜索等后续分支功能在本版缺席。歌词偏移继续按曲目保存在本机。

## 平台

- Android 提供正式签名 APK。
- Windows 提供 x86_64 安装程序。
- Linux x86_64 提供便携包和 DEB，播放使用系统 FFmpeg。
