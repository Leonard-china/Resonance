## 一、项目定位与核心理念

Resonance 是一款专为 **Android** 与 **Windows** 打造的原生本地音乐播放器，坚持 **本地优先（Local-First）** 与 **数据自治**：

- **无强制云端账号**：音乐库、自建歌单、播放队列、点赞历史与偏好设置全量保存在用户设备本地；独立官网与匿名论坛不与用户曲库连接。
- **纯净原生架构**：Kotlin Multiplatform 与 Compose Multiplatform 原生构建，兼具 Android Media3 后台播放服务与 Windows 平台原生音频调度。
- **强大的扩展能力**：支持高质量本地音频播放、全自动音量平衡（ReplayGain/LUFS）、双语歌词与跨平台后台桌面悬浮歌词、B 站音频导入、双端内置本地离线 OCR 歌单识别，以及深度集成的多模型音乐助手。

## 二、v0.4.7 核心新功能亮点

### 2.1 MusicFree 核心歌源生态与录音室版本甄选

在新版本中，Resonance 引入了轻量级原生 QuickJS 脚本引擎，正式接入开放歌源插件能力：

- **插件格式兼容**：支持导入与运行符合 MusicFree 规范的核心歌源脚本，实现跨源歌曲检索、多档音质提取、专辑封面与同步歌词获取。
- **沙箱安全与权限隔离**：歌源脚本运行在隔离的 QuickJS 环境中，无任何主机反射、文件系统或 API 凭据访问权限；网络请求强制限定于公网安全 HTTPS（443端口），严禁探测内网 IP 或截留敏感信息；内置 32MB 内存、512KB 栈空间与 5 秒执行保护。
- **录音室版本甄选与候选打分**：系统智能识别 live、翻唱、现场、混音等非目标版本，优先选取官方录音室原版；真实记录音频与封面来源（如“网易云音乐”、“QQ音乐”、“本地目录”），在歌曲信息与详情面板中清晰溯源。

### 2.2 每日推荐闭环：去重、7天冷却与点赞/踩/评论

推荐系统迎来重大进化，从单纯算法推荐走向真实乐迷偏好交互：

- **跨会话去重与 7 天冷却**：推荐历史独立持久化存储，同一歌曲（按标准 NFKC 歌手+歌名匹配）即便存在多份本地文件也仅计一次；已推歌曲进入默认 7 天滚动冷却期，杜绝近期高频循环推歌。
- **推荐卡片赞踩交互**：
  - **点赞（Like）**：提升该歌手与专辑在后续选曲中的权重；即使未保存到歌单，点赞状态亦长期保留。
  - **点踩（Dislike）**：降低该曲目及相关维度的推荐倾向，过滤该曲不再重复推荐。
  - **撤销与切换**：点赞与点踩互斥且支持随时撤销，尊重乐迷即时听觉变化。
- **本地乐迷短评**：支持对推荐曲目输入最多 500 字的个人短评；短评纯本地加密保存，提取风格偏好词作为本地种子供后续选曲参考，全流程无需调用外部模型。
- **一键入单保护**：推荐曲目支持单曲或多选直接保存至已有或新建的自建歌单；新一轮推荐换批时，系统智能识别收藏状态与歌单归属，对用户已保留歌曲实施物理删除豁免保护。

### 2.3 应用下载与存储空间管理：安全释放与失败回滚

随着音源与导入功能日益丰富，专设“下载与空间”管理中心，全面掌控设备存储：

- **托管空间可视化**：精确统计 Resonance 托管音频与封面的总占用空间，支持对同 SHA-256 的重复文件进行识别标记。
- **智能清理预览**：清理前提供完整明细预览，展示拟清理的临时推荐曲目，杜绝误删风险。
- **“释放已保存音频”模式**：对于已收藏或已加入自建歌单但希望腾出磁盘空间的歌曲，用户可选择“释放已保存音频”——系统仅安全删除本地音频文件并置空存储路径，曲目元数据、歌单位置、封面及点赞评论完好保留；后续联网时可直接一键重新按原源下载入库。
- **文件独占与失败回滚**：针对 Windows 平台常见的文件占用（如其他播放进程锁定）导致删除失败的情况，系统通过事务保障捕获具名异常并进行曲库快照原子回滚，避免曲库“数据丢失但文件残留”的状态不一致。

### 2.4 单曲歌词校准与手机窄屏双语排版适配

彻底解决个别曲目因前奏剪辑或版本差异导致的歌词快慢漂移问题：

- **微秒级双向时间校准**：播放器歌词页新增校准控制器，支持以 500ms 为步长进行“提前”或“延后”微调，支持范围达 ±600 秒；调整后即时生效听感同步，并在 `lyrics-cache/offsets/` 下实现原子写入，重新切歌或重启依然保持校准。
- **手机窄屏长标题稳固排版**：针对手机设备窄屏显示优化播放器顶栏布局，超长歌名与歌手信息采用平滑截断与优雅对齐，确保前奏倒计时、播放进度与多功能弹窗在各种屏幕比例下均清晰舒适。
- **双语歌词层级清晰**：双语翻译与原歌词采用区分字阶与对比度排版，主歌词饱满吸睛，译文柔和跟进，营造舒适沉浸的视觉体验。

### 2.5 音乐助手播放导航与离线本地帮助

AI 音乐助手的系统级调度能力进一步扩展：

- **播放与导航执行工具**：助手新增 `play_tracks`、`seek`、`next`、`previous`、`set_playing` 以及 `open_page` 工具，能够根据乐迷指令直接控制播放器队列、切换曲目、调节进度或跳转至“曲库/推荐/设置/歌源”等特定页面。
- **离线常见问题解答（零 Token 消耗）**：内置离线帮助词典，用户询问“如何设置悬浮歌词”、“怎么导入 B 站音乐”、“如何校准歌词”等高频问题时，助手优先检索内置使用教程直接给出图文步骤解答，完全在本地毫秒级响应，不产生任何 API 请求与费用。

### 2.6 全局页面滑动手势：主导航与曲库自然切换

为触控设备与触摸屏笔记本带来极度顺滑的自然手势操作：

- **多层级左右滑动手势**：
  - **主导航级**：在非嵌套区域横滑即可在“音乐库”、“音乐助手”与“工具箱”三大主模块间顺畅切换。
  - **曲库栏目级**：在曲库主页左右横滑，可在“歌曲”、“歌单”、“专辑”、“歌手”四项分类间直觉切页。
  - **播放器面板级**：在全屏播放器界面横滑，可自然切换“黑胶封面”、“滚动歌词”与“当前队列”。
- **防误触与阻尼防护**：
  - 起点位于屏幕左右 24dp 边缘区域时自动退出，优先保留系统边缘返回手势；
  - 采用水平位移（>50dp）与滑动初速度（>400dp/s）复合阈值判定，竖向列表滚动与进度条拖拽不受任何干扰；
  - 首页与尾页具备阻尼回弹，不发生循环回卷跳变。

### 2.7 关于页动态呈现当前版本发布特性

应用设置中的“关于 Resonance”页面全面升级：

- **构建期动态注入**：在打包过程中自动解析当前版本的发布日志，将正式版本号、发布日期以及核心特性清单注入应用。

## 三、快速上手与升级指引

### 覆盖升级说明
- **Android 用户**：直接安装 `Resonance-0.4.7-release.apk` 覆盖旧版本。应用采用官方正式发布密钥签名，升级过程中曲库索引、本地歌单、AI 对话历史及设置配置全量无缝继承。
- **Windows 用户**：运行 `Resonance-0.4.7.exe` 安装向导完成覆盖安装即可，内置完整的 JRE 运行时与 FFmpeg 编解码支持，无需单独安装依赖。

### 首次使用推荐步骤
1. 打开应用后，可先在引导页选择“快速了解”或“跟着操作”，快速建立对播放器布局的认知。
2. 进入“工具箱 → 扫描系统音频”扫描设备本地已有的无损/MP3 音乐，自动生成专辑与歌手归类。
3. 若需导入歌源，进入“设置 → 歌源管理”，点击导入歌源脚本，即刻畅享跨源搜索与下载。
4. 打开播放器面板，体验顺滑的左右滑动手势；若歌词稍有偏差，轻触校准按钮即可一键修正。

## 四、隐私、安全性与技术边界

- **完全本地优先**：所有歌曲音频、歌单结构、推荐评分、个人短评与歌词偏移全部以标准 JSON/原子文件存储在用户设备私有目录中。
- **无静默网络开销**：普通播放、本地曲库管理、音量平衡、手势切页与离线帮助 100% 离线运行；仅在用户主动发起网络搜索、在线识词、模型聊天或下载时发生受控的公网 HTTPS 请求。
- **凭据硬件级保护**：若用户配置了第三方云端模型 API Key 或 B 站 Cookie，Windows 端使用系统原生 DPAPI 加密，Android 端使用 Android Keystore AES-GCM 硬件级隔离存储。
