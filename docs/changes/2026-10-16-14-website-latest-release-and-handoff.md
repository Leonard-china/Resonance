## 需求或问题

官网实现期间播放器已由其他发布工作更新到 v0.4.2，但本地官网的运行数据仍提供 v0.4.1。用户要求官网只提供最新版，并在成功更新后删除网站存储中的旧安装包。交付说明还需要直接说明作者页面各项操作。

## 原因与依据

官网源码与运行数据隔离，不会在播放器发布时自动导入安装包。`manage.py import-release` 从工程唯一版本源读取版本、同版发布说明及真实文件，经 `releases.publish` 切换；无需修改播放器或网站发布逻辑。GitHub CLI 查询的最新正式 Release 为 v0.4.2，文件大小与本机发布产物一致。
