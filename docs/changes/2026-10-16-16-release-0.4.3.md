## 需求或问题

用户在手机端使用「歌单导入与导出」功能导出歌单时，遭遇“同步失败: No album art found”阻断。在代码完成安全捕获与内嵌封面回退修复并通过自动化测试后，用户明确要求：“构建并推送”。

需要执行完整的正式构建、自动化测试、签名校验、产物清单哈希生成、文档同步，生成正式签名的 Android Release APK 与 Windows 安装包并推送 GitHub Release。

## 原因与依据

1. 解决了移动端歌单归档导出的关键异常，依据版本管理规范，递增发布版本至 `0.4.3`（versionCode `26`），确保用户在 Android 和 Windows 设备上可正常覆盖升级。
2. 遵守 AGENTS.md 规则，发布产物必须由本次源码全新构建并从实际产物生成校验和，严禁复用旧值；密钥不输出、不入库。
