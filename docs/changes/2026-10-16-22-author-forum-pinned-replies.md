# 2026-10-16 — 作者登录后参与论坛并置顶作者回复

- 修改日期：2026-10-16（Asia/Shanghai）
- 类型：功能
- 适用版本：播放器 `0.4.4 / 27`，未升版
- 影响平台：独立官网论坛，电脑和手机浏览器
- 关联需求：用户希望作者身份仍能参与论坛，回复带作者标签并置顶

## 需求或问题

原实现已经根据作者登录会话保存 `is_author` 并显示作者标签，但回复按 ID 排序，没有作者置顶。发帖和回复表单在作者登录后仍提示匿名并提供无效昵称输入，身份表现不清楚。

## 原因与依据

`author()` 从服务端已验证会话返回作者身份，不信任用户输入的身份字段；该链路可保留。回复读取需要按作者身份优先，模板需要按当前登录身份给出正确说明。

## 具体修改

| 文件 | 关键符号 | 实际修改 |
| --- | --- | --- |
| [app.py](../../website/app.py) | `post` 回复查询 | `ORDER BY is_author DESC,id`，所有读者都先看到作者回复，同组保持原时间顺序；不更改每帖 200 回复上限。 |
| [post.html](../../website/templates/post.html) | `reply-author`、`pinned-label` | 作者回复显示作者与置顶标签，增加轻量强调；已登录作者回复表单明确身份，隐藏无效昵称栏。 |
| [compose.html](../../website/templates/compose.html)、[forum.html](../../website/templates/forum.html) | 身份说明 | 作者登录后明确以作者身份发帖/参与；访客继续匿名且不显示后台入口。 |
| [site.css](../../website/static/site.css) | 作者回复样式 | 使用现有墨绿色和浅绿背景，保留手机单列布局。 |
| [test_site.py](../../website/tests/test_site.py) | 作者参与、置顶及重启回归 | 验证作者发帖/连续回复、退出后恢复匿名、访客伪造字段/昵称不能获标签、普通读者看到置顶、旧回复无需迁移即可排序。 |

## 修改前后行为

| 场景 | 修改前 | 修改后 |
| --- | --- | --- |
| 作者登录后进入论坛 | 功能可用但仍提示匿名 | 明确作者身份，可正常发帖回复 |
| 作者晚于访客回复 | 排在访客之后 | 作者回复区内置顶，显示作者/置顶标签 |
| 旧数据 | 已有 `is_author` 字段 | 直接使用，无数据库迁移或内容改写 |

## 平台与数据影响

没有数据库结构变更，不改已有留言内容，不替用户发生产留言。会话到期或退出后恢复匿名。置顶仅作用于帖子内部作者回复；普通帖子列表仍按最近更新排序。作者入口和密码不写进公共模板或文档。

## 限制与后续

生产论坛不创建测试留言；作者真实操作由用户自己的登录会话进行。多条作者回复都置顶并按发布时间排序，不会自动置顶整个主题帖。
