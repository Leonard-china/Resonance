# 2026-10-17 — 升版 0.4.7、构建并打包 Android Release APK 与 Windows 安装包

- 修改日期：2026-10-17（Asia/Shanghai）
- 类型：构建 / 发布 / 文档
- 适用版本：0.4.6 / 29 → 0.4.7 / 30
- 影响平台：共享 / Android / Windows
- 关联记录或需求：用户明确要求“构建新的release-apk和exe和新版介绍md”，包含 05~14 号所有已完成并验证的功能与修复。

## 需求或问题

在完成歌源生态接入、推荐去重/冷却/赞踩评论、下载空间管理与回滚、单曲歌词时间校准与手机窄屏布局、音乐助手播放/导航工具与离线本地帮助、全局左右滑动手势以及关于页版本亮点展示等功能的全链路回归验证后，按照用户指令正式升版并构建双平台 Release 产物（APK 与 EXE），产出对应的新版介绍与发布说明文档。

## 原因与依据

1. **版本规范**：依据 `AGENTS.md`，版本号以 `version.properties` 为唯一来源，正式发布时显式升版：`versionName` 由 `0.4.6` 升级为 `0.4.7`，`versionCode` 由 `29` 递增至 `30`。
2. **构建任务自动化**：执行 `scripts/build.ps1 -BumpVersion` 触发全量回归测试（`allTests`）、Android Release 静态代码分析（`lintRelease`）、签名 APK 打包（`assembleRelease`）与 Windows 安装包制作（`packageReleaseExe`），并调用 `scripts/release-manifest.ps1` 收集最终产物到 `release/0.4.7/`，实时计算 SHA-256 并回填至发布说明文档。
3. **版本更新特性提取**：Gradle 任务 `generateAppVersion` 自动读取 `docs/RELEASE_NOTES-0.4.7.md` 中的“## 主要更新”条目，自动生成 `BuildVersion.kt`，使得应用设置中的“关于”页面能够离线展示新版核心更新要点。

## 平台与数据影响

- **跨平台共享**：`BuildVersion.kt` 自动更新版本常量，两端代码行为一致。
- **Android 端**：由官方发布证书签名打包 `Resonance-0.4.7-release.apk`，支持从旧版本平滑覆盖安装，完全保留曲库数据与偏好。
- **Windows 端**：由 Compose Desktop 打包完整可分发运行环境 `Resonance-0.4.7.exe`，集成 JRE 运行时与 FFmpeg。
- **数据兼容性**：歌源脚本、歌词偏移（`lyric-offsets.json`）、推荐历史（`recommendation-history.json`）、赞踩反馈（`recommendation-feedback.json`）与下载托管索引（`ownedAudio`）格式完全向下兼容。
