# 2026-10-17 — 升版 0.4.8、构建并打包 Android Release APK 与 Windows 安装包

- 修改日期：2026-10-17（Asia/Shanghai）
- 类型：构建 / 发布 / 文档
- 适用版本：0.4.7 / 30 → 0.4.8 / 31
- 影响平台：共享 / Android / Windows
- 关联记录或需求：用户需求“1.滑动屏幕换页时没有动画效果 2.优化动画流畅度 3.我希望能内置几个歌源，不让用户自己搜搜”以及“构建新的发布版”。

## 需求或问题

在完成左右滑动实时跟手动画、曲库四标签流体过渡、动态裁剪（`SizeTransform`）重排开销优化，以及双端开箱即用内置网易云音乐、酷我音乐、酷狗音乐三大主流公网免配置歌源后，按照用户指令正式升版至 `0.4.8 / 31`，执行全量自动化测试与 Lint 校验，构建 Android Release 签名 APK 与 Windows 安装包，并生成完整的发布说明、新版介绍文档及产物校验和清单。

## 原因与依据

1. **版本规范**：依据 `AGENTS.md`，版本号以 `version.properties` 为唯一来源，正式发布时显式升版：`versionName` 由 `0.4.7` 升级为 `0.4.8`，`versionCode` 由 `30` 递增至 `31`。
2. **构建任务自动化**：执行 `powershell.exe -ExecutionPolicy Bypass -File scripts\build.ps1 -NoBump` 触发全量回归测试（`allTests`）、Android Release 静态代码分析（`lintRelease`）、签名 APK 打包（`assembleRelease`）与 Windows 安装包制作（`packageReleaseExe`），并调用 `scripts/release-manifest.ps1` 收集最终产物到 `release/0.4.8/`，实时计算 SHA-256 并自动回填至发布说明文档。
3. **版本更新特性提取**：Gradle 任务 `generateAppVersion` 自动读取 `docs/RELEASE_NOTES-0.4.8.md` 中的“## 主要更新”条目，自动生成 `BuildVersion.kt`，使得应用设置中的“关于”页面能够离线展示新版核心更新要点。

## 平台与数据影响

- **跨平台共享**：`BuildVersion.kt` 自动更新版本常量，两端代码行为一致。
- **Android 端**：由官方发布证书签名打包 `Resonance-0.4.8-release.apk`，支持从旧版本平滑覆盖安装，完全保留曲库数据与偏好。
- **Windows 端**：由 Compose Desktop 打包完整可分发运行环境 `Resonance-0.4.8.exe`，集成 JRE 运行时与 FFmpeg。
- **数据兼容性**：自动检查并预置网易云音乐、酷我音乐、酷狗音乐三大内置歌源（标记 `isBuiltin = true`），原有用户自建插件、自建歌单与曲库完全兼容且不受任何破坏。
