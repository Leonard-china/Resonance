# 2026-10-17 — 升版 0.4.9、构建并打包 Android Release APK 与 Windows 安装包

- 修改日期：2026-10-17（Asia/Shanghai）
- 类型：构建 / 发布 / 文档
- 适用版本：0.4.8 / 31 → 0.4.9 / 32
- 影响平台：共享 / Android / Windows
- 关联记录或需求：用户需求“构建发布版并推到github和网站”，包含 19 号歌源网络放开与智能回退、20 号二级页面顶部黑边消除的所有修复与回归成果。

## 需求或问题

在完成公网歌源 HTTP/HTTPS 协议放开与重定向支持、跨源多候选智能回退机制、酷我 10 秒试听片段拦截防伪，以及工具二级页面转场尺寸裁剪黑边消除后，按照用户指令正式升版至 `0.4.9 / 32`，执行全量自动化测试与 Lint 校验，构建 Android Release 签名 APK 与 Windows 安装包，并完成发布说明、新版介绍文档、GitHub 发布与官网生产同步。

## 原因与依据

1. **版本规范**：依据 `AGENTS.md`，版本号以 `version.properties` 为唯一来源，正式发布时显式升版：`versionName` 由 `0.4.8` 升级为 `0.4.9`，`versionCode` 由 `31` 递增至 `32`。
2. **构建任务自动化**：执行 `powershell.exe -ExecutionPolicy Bypass -File scripts\build.ps1 -NoBump` 触发全量回归测试（`allTests`）、Android Release 静态代码分析（`lintRelease`）、签名 APK 打包（`assembleRelease`）与 Windows 安装包制作（`packageReleaseExe`），并调用 `scripts/release-manifest.ps1` 收集最终产物到 `release/0.4.9/`，实时计算 SHA-256 并自动回填至发布说明文档。
3. **版本更新特性提取**：Gradle 任务 `generateAppVersion` 自动读取 `docs/RELEASE_NOTES-0.4.9.md` 中的“## 主要更新”条目，自动生成 `BuildVersion.kt`，使得应用设置中的“关于”页面能够离线展示新版核心更新要点。
