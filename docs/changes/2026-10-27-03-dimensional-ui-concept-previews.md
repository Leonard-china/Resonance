- 修改日期：2026-10-27（Asia/Shanghai）
- 类型：设计预览 / 文档
- 适用版本：当前 `0.6.0 / 34`；未改变版本号
- 影响平台：Android 原生界面的视觉方向探索；未修改 Android / Windows 运行代码
- 关联需求：用户反馈上一轮 UI 缺少立体感，要求先提供 20 张预览图
- 关联记录：[上一轮原生 UI 与动效优化](2026-10-27-02-native-ui-and-motion-polish.md)

## 需求或问题

用户希望先看到更明显的卡片厚度、浮起和凹陷、材质边缘及控件光影，再确定下一轮实现方向。此次交付以静态概念图为范围，不把效果图当作已经实现的界面。

## 原因与依据

此前代码以统一层级、可读性与克制反馈为主，变更记录明确包含减弱玻璃边缘和默认阴影。用户此次反馈说明这种方向没有达到其期望的立体程度；这是设计偏好调整，不据此推断存在功能缺陷。

沿用用户已选择的青绿与封面氛围，用 imagegen 内置工具分别生成 20 个方案。每张固定展示曲库和完整播放器，采用相近的示例内容、常规线性进度条和现有主要导航，重点比较层次与材质。示例封面和歌曲内容由生成提示词指定，未读取用户曲库。

## 限制与后续

这些图片是生成式静态概念图，不是实际 Compose 截图；少量文字、图标、布局细节以及控件数量存在生成差异，不能直接作为像素级实现规格。没有验证图片中的触控范围、可访问性、滚动行为、动效或性能。后续应根据用户选中的编号明确材质、阴影、边缘高光和层级规范，再在原生 UI 中实现并验证。深色玻璃、复杂折射等效果的具体实现成本仍需届时评估。
