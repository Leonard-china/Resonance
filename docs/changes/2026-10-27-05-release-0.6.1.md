## 原因与依据

1. **版本规范**：依据 `AGENTS.md`，版本号以 `version.properties` 为唯一来源，正式发布时显式更新：`versionName=0.6.1`、`versionCode=35`。
2. **全流程自动化构建与校验**：通过 `scripts\build.ps1 -NoBump` 自动化执行全量测试套件、Release Lint、Android 签名打包与 Windows EXE 打包，并调用 `scripts/release-manifest.ps1` 收集二进制至 `release/0.6.1/`，实时计算 SHA-256 并回填至 `docs/RELEASE_NOTES-0.6.1.md`。
3. **版本更新特性提取**：Gradle `generateAppVersion` 自动读取 `docs/RELEASE_NOTES-0.6.1.md` 中的“## 主要更新”条目生成 `BuildVersion.kt`，通过 `HorizontalPageSwipeUnitTest` 断言版本号、发布日期与 5 项更新条目全部匹配。
