## 需求或问题

1. 播放器完成了一系列里程碑式的交互、界面与网络功能升级：
   - 参考 Mineradio 重塑的原生沉浸式音乐舞台、大字歌词排版、倾斜封面景深与悬浮播放台；
   - 唱片主题色自适应提取、流动波浪动态底色、切页跳跃回弹弹性阻尼物理动效；
   - 基于点对点端到端加密（TLS 1.3/1.2）的双人直连“与朋友一起听”，无中转服务器，音频与进度实时同步；
   - 一起听极简交互升级：剪贴板智能提取（一键秒连）、自然语言邀请消息容错解析、局域网一键零配置开房与图文指南；
   - 针对 Android 16 与大字号（150%）的界面全域动态避让与边界保护。
2. 将上述所有更新收敛合并，正式升版至 `0.6.4 / 38`，执行全量回归与自动化构建管线。
3. 生成 Android Release APK 与 Windows Release EXE 最终二进制产物，计算可复现 SHA-256 校验和并自动回填发布说明。
4. 同步发布到 GitHub Releases（标签 `v0.6.4`），同时将官网数据库与更新公告同步至现网 `leonard.asia`。

## 原因与依据

1. 遵循仓库规范 `AGENTS.md`：
   - 版本唯一来源为 `version.properties`，升版为 `0.6.4 / 38`；
   - 由 Gradle `generateAppVersion` 任务根据 `version.properties` 与 `docs/RELEASE_NOTES-0.6.4.md` 提取版本号、日期与主要更新，自动生成 `BuildVersion.kt`，并通过 `HorizontalPageSwipeUnitTest` 单元测试断言；
   - 校验和严格基于本次实际产物生成。
2. 构建与发布管线：
   - 执行 `scripts/build.ps1 -NoBump`，完成 `:composeApp:allTests`、`:composeApp:lintRelease`、`:composeApp:assembleRelease` 与 `:composeApp:packageReleaseExe`；
   - 执行 `scripts/release-manifest.ps1 -Version 0.6.4`，生成产物清单与校验表；
   - 官网采用 `manage.py import-release` 与 `publish-announcement` 更新 SQLite 数据库，并调用 `D:\Project\mcServer\deploy_resonance.py` 完成生产容器同步与热重启。
