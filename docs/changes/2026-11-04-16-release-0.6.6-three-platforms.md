# 2026-11-04 — 准备 0.6.6 三端发布并更新本机 Linux 桌面入口

- 修改日期：2026-11-04（Asia/Shanghai）
- 类型：版本发布 / 构建配置 / 本机更新
- 适用版本：从 0.6.5 / 39 显式更新为 0.6.6 / 40；用户本次明确要求发布
- 影响平台：Android、Windows、Linux x86_64
- 关联需求：替换桌面 Resonance 为最新版，构建三个系统发布版并推送 GitHub
- 关联记录：[音量弹窗修复](2026-11-04-15-volume-dialog-window-isolation.md)、[前轮桌面安装](2026-11-04-07-release-phone-update-and-linux-shortcut.md)

## 需求或问题

本机桌面与应用菜单仍通过 `current` 指向 0.6.5 的旧浅色 UI 程序目录，没有本轮歌词、歌源、材质和弹窗修复。GitHub 公开最新版本仍为 v0.6.5，当前工作区包含之后的原生播放器更新；用户要求更新本机并交付 Android、Windows、Linux 发布文件。

## 原因与依据

- 桌面 `Resonance.desktop` 使用固定用户级启动链接，完整 app image 与 Java/runtime 需要一并更新。
- 当前主机为 Linux x86_64，Compose/jpackage 的 EXE 任务需要 Windows；不能把历史 EXE 改名当成本次构建。[Compose 官方分发说明](https://kotlinlang.org/docs/multiplatform/compose-native-distribution.html)明确要求在对应兼容系统打包。
- Git 2.53.0 已安装；origin 为 `Leonard-china/Resonance`，本机最初没有 GitHub CLI 登录。Windows 2025 runner 提供 WiX 3，见[官方镜像工具表](https://github.com/actions/runner-images/blob/main/images/windows/Windows2025-Readme.md)。
