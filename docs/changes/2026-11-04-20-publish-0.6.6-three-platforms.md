## 需求与原因

GitHub 和官网公开最新版本均为 0.6.5；远端 main 已有 0.6.6 初始源码，但此前 Windows 成功构建未包含本轮导出修复。不能发布历史 Windows／Linux 产物或只更新官网版本文字。官网现有受控发布与下载仅支持 Windows／Android，需要兼容性扩展 Linux 后原子发布三端。

## 实际修改与平台影响

1. 提交导出修复及独立变更记录，更新 0.6.6 发布说明；版本保持 0.6.6 / 40，所有三端产物从包含最终修复的源码构建。
2. Windows 使用仓库 `release-windows.yml` 在 Windows 2025 runner 原生打包，运行桌面回归并验证完整 app image 启动和真实 FFmpeg 资源；Linux／Android 在当前 Linux 主机按相同业务源码构建。
3. 官网仅扩展安装包发布／下载能力，不改变帖子、订阅、作者凭据或邮件发送。Linux 沿用现有资产表，旧双端版本和入口保持兼容；更新前备份，全部新包校验后事务切换。
4. `scripts/release-manifest.ps1` 增加当前 Linux 便携包的可选收集，SHA-256 必须从本次文件计算。

不读取或提交真实签名配置／私钥、用户音频、API Key、官网运行数据、本机工具或临时附件；不改曲库、音乐、归档格式或播放器配置。已有无关改动保留，不使用全目录 `git add`。
