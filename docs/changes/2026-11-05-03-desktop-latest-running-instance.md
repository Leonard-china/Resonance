## 需求或问题

前轮已将桌面/菜单的固定启动链路切到 `0.6.6-20261105-am-ui/`，但保留了正在运行的旧进程。本次检查发现较早 `0.6.6-20261104-release/` 的实例和交付目录中另一个实例同时运行；正确的快捷方式指向不等于当前看到的旧窗口已经更新。

## 原因与依据

实际检查桌面及菜单的 `Exec/TryExec`、固定启动链接、`current` 和 `/proc/<pid>/exe`。两个旧实例分别来自旧安装目录与解压的交付目录；桌面文件本身已指向最新版，没有重写相同配置或覆盖旧程序的必要。
