## 需求或问题

前轮已安装 Linux 歌词修复版，并构建包含全部资源类的最终 Android 正式包，但手机 USB 调试连接断开。手机最后一次成功操作是保留数据恢复原 APK，最终修正版尚未安装。本轮在用户确认重新连接后完成手机覆盖与真实启动验收。

## 原因与依据

ADB 本轮重新识别原手机为已授权设备。最终待装 APK 的 SHA-256 为 `6923cb29e1b7495558b2e236eca0dd3532c7945c82dd393a35af7b429ab7af70`，与前轮完整包静态验收记录一致。前轮中间候选缺少资源类的失败记录保留在 09 号记录，不将其混同为本次安装通过。

本轮不新增业务源码改动或重建 APK，使用前轮已完成完整性检查的最终文件；安装前再次核对包名、版本、证书、签名、对齐和每份 DEX 的字节。

## 平台与数据影响

本轮只操作 Android 安装和启动，未修改任何业务源码、版本文件、数据格式、同步协议、权限或音频文件。`install -r` 保留现有应用数据；没有执行正式应用卸载、清除数据、音频删除或元数据写回。签名校验只核对公开证书与 APK，不读取真实签名配置、私钥或用户 API Key。
