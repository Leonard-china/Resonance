# 2026-11-13 — 构建并发布窄屏歌词修复版 0.6.10

- 修改日期：2026-11-13（Asia/Shanghai）
- 类型：正式发布
- 适用版本：0.6.9 / 43 → 0.6.10 / 44
- 影响平台：Android、Windows、Linux x86_64 和官网下载
- 关联记录：[歌词修复](2026-11-13-01-fit-long-player-lyrics.md)、[上一版发布](2026-11-06-07-publish-0.6.9-release.md)

## 需求或问题

将播放页歌词裁切修复构建为三端正式版本，并更新 GitHub Release 和官网下载。

## 原因与依据

公开版本 0.6.9 的窄屏歌词仍使用固定大字号。本次从 0.6.9 的发布分支建立 0.6.10，固定源码为 `c3ea9d3ae2e964b4b598d5ec8e0be5301782e408`。其他未提交改动保留在原工作区。

## 具体修改

| 文件 | 关键符号 | 实际修改 |
| --- | --- | --- |
| [version.properties](../../version.properties) | `versionName`、`versionCode` | 设置 0.6.10 / 44，作为三个平台的版本来源。 |
| [RELEASE_NOTES-0.6.10.md](../RELEASE_NOTES-0.6.10.md) | 主要更新、产物校验 | 记录歌词修复及从本次正式产物生成的 SHA-256。 |
| [歌词修复](2026-11-13-01-fit-long-player-lyrics.md) | `LyricsContent`、`LyricRow` | 将视口自适应歌词字阶和离屏回归纳入三端构建。 |

## 修改前后行为

0.6.9 的完整歌词页在窄屏上仍使用固定大字号。0.6.10 按实际歌词视口调整字号和行高，长句自然换行并保留系统字号缩放。

## 平台与数据影响

三端采用共享歌词排版。Android 延续既有正式签名。官网通过发布事务切换 Android APK、Windows EXE、Linux 便携包，DEB 入口使用对应 GitHub 附件。版本发布不涉及音频文件、数据迁移或邮件群发。
