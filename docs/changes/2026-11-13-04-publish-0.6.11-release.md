# 2026-11-13 — 构建并发布封面歌词修复版 0.6.11

- 修改日期：2026-11-13（Asia/Shanghai）
- 类型：正式发布
- 适用版本：0.6.10 / 44 → 0.6.11 / 45
- 影响平台：Android、Windows、Linux x86_64 和官网下载
- 关联记录：[封面歌词修复](2026-11-13-03-fit-cover-lyrics-preview.md)、[上一版发布](2026-11-13-02-publish-0.6.10-release.md)

## 需求或问题

用户要求先完整验证封面下方的歌词预览，再将修复推送并发布。

## 原因与依据

0.6.10 的发布回归未覆盖封面预览中的双语长句。本次从 0.6.10 发布分支构建，推送前复现旧布局裁切并验证修复后的预览、完整歌词页和超长歌词入口。

## 具体修改

| 文件 | 关键符号 | 修改 |
| --- | --- | --- |
| [version.properties](../../version.properties) | `versionName`、`versionCode` | 设置 0.6.11 / 45，作为三个平台的版本来源。 |
| [版本说明](../RELEASE_NOTES-0.6.11.md) | 主要更新、校验值 | 记录封面歌词修复和本次安装包的 SHA-256。 |

## 修改前后行为

封面歌词预览从固定行数改为按实际排版高度显示。过长的歌词可点按进入完整歌词继续查看。

## 平台与数据影响

Android 延续原正式签名。官网通过发布事务切换 APK、EXE 和 Linux 便携包，DEB 链接指向对应的 GitHub 附件。发布不迁移本机音频或曲库数据。
