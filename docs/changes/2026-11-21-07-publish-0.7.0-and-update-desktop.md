# 2026-11-21 — 发布清岚 0.7.0 并更新本机桌面播放器

- 类型为三端版本发布与本机安装更新。版本为 `0.7.0 / 70`。
- 关联[清岚界面](2026-11-21-05-clearwater-fresh-ui-apple-motion-and-apk.md)、[歌词校准](2026-11-21-06-lyrics-calibration-toolbar.md)和[本版发布说明](../RELEASE_NOTES-0.7.0.md)。

## 需求、原因与范围

将用户指定工作区的 Android、Windows 与 Linux 版本发布到 GitHub 和官网下载页，并替换本机桌面图标所启动的 Linux 播放器。发布前两处下载渠道与本机安装均为 0.6.12。本次按用户确认使用 0.6.6 分支上开发的 0.7.0 功能集。恢复「一起听」入口，已公开的批量重新定位与歌单搜索在此分支缺席。

## 准备与数据影响

[version.properties](../../version.properties) 已为 0.7.0 / 70。[发布说明](../RELEASE_NOTES-0.7.0.md)供应用内关于页、GitHub 与官网使用。通过独立发布分支固定构建源码。本机安装采用版本目录和已有桌面启动链路，官网使用原受控发布流程。

## 验证与进度

已核实旧版本与本机入口。三端产物、安装及公开下载验证在实际执行后记录。
