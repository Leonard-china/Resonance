# 2026-11-22 — 统一 Android 安装包签名并重新上传 0.7.0

- 适用版本为 Android `0.7.0 / 70`。
- 类型为开发与发布规则、构建校验、Android 重新上传。
- 关联[测试签名覆盖包](2026-11-22-01-android-phone-signature-update.md)与[三端发布记录](2026-11-21-07-publish-0.7.0-and-update-desktop.md)。

## 现象与原因

此前为手机准备的 0.7.0 测试包与公开 0.7.0 APK 使用同一个应用 ID `com.resonance.player` 和不同证书。Android 拒绝这两种签名相互覆盖。公开 0.7.0 已使用正式证书，本次把该证书也固定用于日常开发中交给手机覆盖使用的包。

## 修改前后行为

现在有正式签名配置时，同包名开发交付与正式发布使用相同证书，手机接受后续同包名、同签名且版本兼容的覆盖。缺少正式配置时，独立包名 `com.resonance.player.debug` 可用于 IDE、模拟器和 CI。未签名及测试签名的同包名包会在交付检查失败。
