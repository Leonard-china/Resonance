# Resonance 可选伙伴寻址服务

独立于 `website/`，只在双方明确配置同一服务时使用。**默认关闭，没有内置公共地址，也未部署公网服务。**

服务只临时登记设备公钥标识、允许查询的伙伴标识、最多八个 IP 和伙伴邀请监听端口；120 秒过期，全部在内存，重启清空。双方相互允许且登记仍有效才能查询对方地址；未在线、未授权和已过期使用同样的返回格式。它无法唤醒已关闭的应用，也不能突破防火墙或保证任意 NAT 接通。

房间邀请密钥、音乐、同步状态和聊天继续通过双方 TLS 直连。服务不接收这些内容，也没有房间密码、消息投递或音频中继接口。服务运营者仍可看到访问来源 IP、设备标识和登记的伙伴关系；不宣称匿名。不要把服务当成聊天备份。

## 本地运行与测试

需要 Python 3.10+ 和独立虚拟环境：

```powershell
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python -m unittest -v
.venv/Scripts/python server.py --host 127.0.0.1 --port 8765
```

依赖约束是本次实际验证的 `cryptography 50.0.2` 系列，不代表已检查所有后续版本。原生客户端的 HTTP 回环入口仅用于显式测试，正式配置只允许 HTTPS。

## 自托管边界

将 Python 监听保持在 `127.0.0.1:8765`，由自己管理的 HTTPS 反向代理提供外部入口。代理需限制请求体不超过 16KB、禁用缓存，并限制每来源速率与并发；不要将 Python 调试服务直接暴露公网。TLS 域名、证书续期、服务守护、网络防火墙和运营容量由部署者配置。本仓库尚未验证真实 Ubuntu 部署或公网接通率。

服务没有账户密码和数据库。API 使用设备现有 P-256 签名密钥，请求先获取 60 秒、一次性随机挑战，再签名固定格式的动作/挑战/负载；服务验证后消费挑战，防止请求重放。签名采用库提供的 ECDSA/SHA-256 DER 格式，参见 [cryptography 官方接口](https://cryptography.io/en/latest/hazmat/primitives/asymmetric/ec/)。这与 TLS 的临时 ECDHE 会话密钥不同。

API 白名单：`POST /v1/challenge`、`register`、`lookup`、`withdraw`；`GET /health` 仅返回健康布尔值。登记只接受数值 IP、合法端口及最多 32 个伙伴。重复 JSON 键、未知内容字段、无效签名、过期/重放挑战均拒绝。每来源 120 次/分钟、最多 32 个处理线程，挑战/登记/限速表各最多 10000 条，读取超时五秒。日志不打印请求体、设备标识或来源 IP；前置代理的日志策略需单独配置。

## 本轮验证

Windows Python + cryptography 50.0.2，`python -m unittest -v`：七项通过。覆盖双向授权、过期与撤销、签名和跨动作重放、并发挑战、拒绝私密内容/重复键/越界地址、容量/速率以及真实 HTTP 往返和请求体上限。未将它当作独立安全审计、承载量测试或真实公网部署结果。
